Present, not perfect. by Jamie Wigg · Dad’s Code

How to use this journal

Two minutes. That’s the whole deal.

One page a day. Each page gives you a micro-action to do today and one line to write tonight. Two minutes — that’s it.

Don’t aim for perfect. Aim for present. Miss a day? Just start the next one. No catch-up, no guilt.

— Jamie, Dad’s Code

  1. 1Read the micro-action in the amber box each morning. Keep it in your back pocket for the day.
  2. 2Do it sometime today — it takes two minutes — then tick the box.
  3. 3Write one line tonight: what happened when you tried it. That’s what locks it in.
  4. 4Pause weekly. A short check-in after days 7, 14, 21 and 28, then a final reflection on day 30.
