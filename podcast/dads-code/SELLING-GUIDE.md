# 💰 How to Sell the Dad's Code Products

A practical, non-technical plan for selling 18 digital products solo.

---

## The 3 places to sell (use all three for what each is best at)

### 1. Gumroad — your home base ⭐ (start here)
Best for a solo, non-technical creator. Handles payments, delivery, and tax automatically. You upload a file, set a price, get a shareable link.
- **Sell:** the eBooks, journals, cookbooks (as PDF) **and** the interactive tools (upload the `.html` file as the download — buyers open it in their browser).
- **Fees:** ~10% flat-ish; you keep the customer's email (huge).
- **Alternative:** Payhip (very similar) if you ever want it.

### 2. Amazon KDP — for reach & credibility
Publish the **eBooks + journals + cookbooks** as Kindle eBooks and print-on-demand paperbacks. Massive built-in audience and search.
- **Trade-off:** Amazon takes a bigger cut and you *don't* get the customer's email. Use it for **discovery**, Gumroad for **profit + list-building**.

### 3. Etsy — for the printables
Etsy buyers actively search for **printable PDFs**. List the **Journal, Conversation Cards, and Time Capsule** here — printables sell strongly on Etsy as gifts.

### Special note on the 7 interactive tools 🖥️
These shine best **hosted online** (free), not just as downloads:
- Host the **free "Days Left"** tool on a free host (**Cloudflare Pages / Netlify / GitHub Pages**) → it becomes your **viral top-of-funnel**: people use it, feel something, share it, and click through to your paid stuff + email list.
- Sell the paid tools (Play Machine, Dad Deck, etc.) as **Gumroad downloads**, or host them behind a simple "enter your email / paid link" gate later.

## Step-by-step: get your first sale (do this once)

1. **Make the files sellable:** open each product's HTML → **Print → Save as PDF** (for the book/printable products). The interactive tools stay as `.html`.
2. **Covers:** make each cover in **Canva** using the cover briefs already in each product's `.md` spec.
3. **Create a Gumroad account** (free). Add a product → upload the file → set the price → paste the **sales description** (I'll write these) → **Publish** → copy the link.
4. **Set up an email tool** (MailerLite free tier) and make the **free lead magnet** ("The 5-Minute Present Dad") the sign-up reward.
5. **Link everything** from your podcast + TikTok/IG bio.

## Pricing & funnel (the money map)

**Free** → **Email list** → **$7–9 tripwire** → **$12–15 core** → **Bundles** → later: memberships/coaching.

- 🎣 **Free hook:** "Days Left" tool + the 5-Minute Present Dad PDF → builds the list.
- 💵 **Tripwire ($7–9):** Play Machine · Conversation Cards.
- 💷 **Core ($12–15):** eBook, journal, cookbooks, ADHD Playbook, Dad Deck, the tools.
- 💎 **Premium ($19):** Letters to You · the full memoir.
- 📦 **Bundles (best margin):**
  - *Dad's Kitchen Bundle* (Kitchen + Dad Fuel) — $22
  - *Mind & Body Bundle* (ADHD Playbook + Steady + 90-Day) — $29
  - *Present Dad Toolkit* (all 7 interactive tools) — $39
  - *Everything Bundle* (all 18) — $79

## How people actually find it (traffic)
1. **Podcast** — mention products in episodes; link in show notes.
2. **TikTok + Instagram** — clips (already scripted in SOCIAL.md) → "link in bio."
3. **The free "Days Left" tool** — the shareable viral piece; every visit can capture an email.
4. **Email list** — where the real selling happens: give value weekly, sell occasionally.

⚠️ **Don't** publish all 18 at once. Launch with **1 free + 3 paid + 1 bundle**, get the store live, learn what sells, then add the rest.
