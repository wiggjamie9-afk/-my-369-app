# Handover — The 48: AI's Best Mate (v1)

Built 2026-11-13 from `THE48-BEST-MATE-builder-spec` and the feature teardown.
Original design and code throughout. Nothing was copied from any other product:
no branding, layout, wording, screenshots or prices. The competitor screenshots
were read for the list of feature *categories* only, as the spec instructed.

## Read this first

1. **Every seeded price is a placeholder.** The 50 starter parts carry round-number
   stand-in costs that I made up so the app could be exercised. They are not
   supplier prices. Each is stored as `placeholder`, shows a "check price" badge on
   quotes, and the review step will not send until a person ticks that they have
   checked them. Import your supplier list (Parts > Import) before quoting real jobs.
2. **Jane's voice is a stub.** The mic records and posts audio, but with no voice
   server connected `/api/voice/listen` returns a fixed sample sentence and
   `/api/voice/speak` returns a chime. The screen says so. Typing the job works now.
3. **It lives in `best-mate/` inside the `-my-369-app` repo**, on branch
   `claude/busy-fermat-69odbh`, not in its own clean repo. The spec asked for a
   clean repo; I can only write to this one. The folder is self-contained, so moving
   it is `cp -r best-mate <new repo>`.

## What is built and tested

| Spec item | Status |
|---|---|
| 1. Quote builder | Built. Job type, brand, cycle, indoor units; lines with cost, markup, sell; margin panel (materials cost / labour cost / net profit); GST ex and inc |
| 2. Parts library | Built. 50 seeded parts, vendor discounts, search and paging, CSV import. Tested with 15,050 parts (search under a second) |
| 3. Voice-to-quote (Jane) | Built against the contract with a local stub. Dictation or typed text becomes a draft quote |
| 4. PDF quote | Built. Header with logo and business details, customer, scope, system summary, price table, GST totals, terms, page numbers. Drafts are watermarked DRAFT |
| 5. Jarvis panel | Built at `/jarvis`: pipeline by state, needs-attention list, recent activity, health strip, and a marked slot for the existing console |
| 6. Settings | Built. Business details, markup, labour rates, preferred brands, payment terms, vendor discounts |

Hard rules:

- **AI never sets a final price** — every quote is created as `draft`; `send` needs
  `reviewed: true` from a person and is refused while any line is unpriced, any
  drafting warning is unread, or placeholder prices are unconfirmed. Editing or
  reopening a quote clears the review. Tested in `test_api.ReviewGate`.
- **No API keys in the repo** — all from environment; `config.example.json` ships
  empty; a test scans the tree for anything key-shaped.
- **Deterministic money maths** — `bestmate/money.py`, 20 unit tests with
  hand-worked expected values.
- **AI output checked before display** — `drafting.check_ai_items` and
  `drafting.scrub_notes`; tested against a fake model that invents prices.
- **Offline-tolerant PWA** — service worker keeps the app shell and the last quotes,
  parts and settings fetched. Offline is read-only: changes are refused with a
  message rather than queued.
- **iPhone Safari first** — see "Not verified" below.

- **Sending.** "Send quote" marks the quote sent and makes the final PDF available

- **From the teardown, skipped for v1 as it said:** the AI room visualiser and a

## Decisions I made that you may want to change

- **Stack:** standard library Python and SQLite, no framework, no front-end build.
  Reason: your next hand can read every line, and deploy has no install step.
- **Install recipes** (`drafting.recipe`): what a split, multi-split, ducted or
  service job normally needs, with default pipe runs and labour hours. These are my
  starting assumptions, not your practice. Adjust the quantities there.
- **Defaults:** 30% markup, $60/h labour cost, $110/h labour charge, 30-day
  validity, 50% deposit terms. All editable in Settings.
- **GST** is calculated once on the ex-GST total, not per line.
- **A brand you don't stock** (say, Samsung) is kept as said and flagged, never
  swapped silently for your preferred brand.
- **Logo:** used as supplied. The app icon and PDF mark are a square crop of the
  circular mark, not redrawn.

# The 48 — AI's Best Mate: Quotes

A quoting app for Australian tradies, built for the phone. Say or tap the job, get a
draft with prices from your own parts library, review it, and send a PDF quote with
GST worked out to the cent.

Pure Python 3 standard library on the server, plain HTML/CSS/JavaScript in the
browser. Nothing to `pip install`, nothing to compile, no keys in the repo.

## Run it (4 commands)

```bash
cd best-mate
python3 -m unittest discover -s tests     # 50 tests: money maths, fabrication check, end to end
python3 server.py                         # http://127.0.0.1:8048/
# open the address in a browser; on a phone it needs HTTPS (see Deploy)
```

## Deploy to a fresh Linux box (1 command)

```bash
bash deploy.sh
```

It checks Python, runs the tests, creates a sign-in password on the box, and starts
the app (a systemd service when run as root, otherwise a background process). It
prints the address, the password once, and the Caddy lines to add when you want it
on a public HTTPS address. It never touches DNS, Caddy or any other service.

## What is in it

| Screen | Route | What it does |
|---|---|---|
| Quotes | `/` | Every quote, filtered by Draft / Sent / Won / Lost |
| New | `/new` | Quote builder form: job type, brand, cycle, indoor units |
| Jane | `/voice` | Say or type the job; a draft quote comes back |
| Quote | `/quote/N` | Lines, labour, margin, GST totals, Review and send, PDF |
| Parts | `/parts` | Priced library, supplier CSV import, add a part |
| Settings | `/settings` | Business details for the PDF, markup, labour rates, vendor discounts |
| Jarvis | `/jarvis` | Job pipeline, quote states, system health |

## The rules it enforces

- **The AI never sets a final price.** Every quote starts as DRAFT. The only way out
  is `POST /api/quotes/N/send` with a person's review, enforced on the server.
- **Prices only come from the parts library.** An item the AI suggests that is not in
  the library is kept as a flagged line with no price. A dollar figure the AI writes
  that the library cannot account for is removed and reported.
- **Money maths is deterministic.** `bestmate/money.py`: integer cents, half-up
  rounding, GST once on the total. No AI and no floating point near the numbers.
- **No keys in the repo.** Everything secret comes from environment variables.

## Configuration

Environment variables (or `config.json`, copied from `config.example.json`):

| Variable | Purpose |
|---|---|
| `APP_PASSWORD` | Sign-in password. Required before the app will listen beyond this machine |
| `HOST`, `PORT` | Where to listen. Default `127.0.0.1:8048` |
| `BESTMATE_DB` | SQLite file. Default `data/bestmate.db` |
| `VOICE_BASE_URL`, `VOICE_KEY`, `VOICE_NAME` | Jane's voice server. Unset = local stub |
| `LLM_BASE_URL`, `LLM_KEY`, `LLM_MODEL` | OpenAI-compatible model for reading the job. Unset = built-in reader |

## The two contracts

```
POST /api/voice/speak   {"text": "..."}             -> audio/wav
POST /api/voice/listen  <audio bytes>               -> {"text": "..."}
POST /api/ai/draft-quote {"job_description": "..."} -> {"line_items": [...], "notes": "...", "flags": [...]}
```

With `VOICE_BASE_URL` set, the two voice calls are passed to the same paths on that
server. With `LLM_BASE_URL` set, the job description goes to `/chat/completions`
there; its answer is then checked against the parts library before anything is shown.

"""Configuration: environment variables first, then an optional config.json. No secret lives in the repo."""
import json
import os

KEYS = {
    # name: (environment variable, default)
    "host": ("HOST", "127.0.0.1"),
    "port": ("PORT", "8048"),
    "db": ("BESTMATE_DB", ""),
    "app_password": ("APP_PASSWORD", ""),
    "session_secret": ("SESSION_SECRET", ""),
    "llm_base_url": ("LLM_BASE_URL", ""),
    "llm_key": ("LLM_KEY", ""),
    "llm_model": ("LLM_MODEL", ""),
    "voice_base_url": ("VOICE_BASE_URL", ""),
    "voice_key": ("VOICE_KEY", ""),
    "voice_name": ("VOICE_NAME", "jane"),
    "voice_stub_text": ("VOICE_STUB_TEXT", ""),
}


def load(root):
    cfg = {}
    path = os.environ.get("BESTMATE_CONFIG") or os.path.join(root, "config.json")
    try:
        with open(path, encoding="utf-8") as fh:
            data = json.load(fh)
        if isinstance(data, dict):
            cfg = {k: str(v) for k, v in data.items() if k in KEYS and v not in (None, "")}
    except FileNotFoundError:
        pass
    for key, (env, default) in KEYS.items():
        if os.environ.get(env):
            cfg[key] = os.environ[env]
        cfg.setdefault(key, default)
    cfg["port"] = int(cfg["port"])
    cfg["db"] = cfg["db"] or os.path.join(root, "data", "bestmate.db")
    return cfg

"""SQLite storage: settings, vendors, parts library, quotes and their lines.

One short-lived connection per call keeps this safe under the threaded server.
The parts table is indexed for search and paging, so it holds 15,000+ rows
as comfortably as the 50 it ships with.
"""
import csv
import io
import json
import os
import sqlite3
import time
from contextlib import contextmanager

from . import money
from .seed_parts import SEED_PARTS, SEED_VENDORS

SCHEMA = """
CREATE TABLE IF NOT EXISTS settings(key TEXT PRIMARY KEY, value TEXT NOT NULL);
CREATE TABLE IF NOT EXISTS vendors(name TEXT PRIMARY KEY, discount_bp INTEGER NOT NULL DEFAULT 0);
CREATE TABLE IF NOT EXISTS parts(
  sku TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  category TEXT NOT NULL DEFAULT '',
  brand TEXT NOT NULL DEFAULT '',
  vendor TEXT NOT NULL DEFAULT '',
  unit TEXT NOT NULL DEFAULT 'ea',
  cost_cents INTEGER NOT NULL,              -- supplier list cost, before vendor discount
  kw_milli INTEGER,                         -- capacity for units, else NULL
  price_status TEXT NOT NULL DEFAULT 'supplier',   -- placeholder | supplier | manual
  active INTEGER NOT NULL DEFAULT 1,
  updated_at INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS parts_name ON parts(name COLLATE NOCASE);
CREATE INDEX IF NOT EXISTS parts_cat ON parts(category, brand, kw_milli);
CREATE TABLE IF NOT EXISTS quotes(
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  number TEXT NOT NULL UNIQUE,
  state TEXT NOT NULL DEFAULT 'draft',      -- draft | sent | won | lost
  source TEXT NOT NULL DEFAULT 'manual',    -- manual | form | voice | ai
  customer_name TEXT NOT NULL DEFAULT '',
  customer_phone TEXT NOT NULL DEFAULT '',
  customer_email TEXT NOT NULL DEFAULT '',
  site_address TEXT NOT NULL DEFAULT '',
  job_title TEXT NOT NULL DEFAULT '',
  scope TEXT NOT NULL DEFAULT '',
  notes TEXT NOT NULL DEFAULT '',
  job_description TEXT NOT NULL DEFAULT '', -- what the tradie said or typed
  spec_json TEXT NOT NULL DEFAULT '{}',     -- install type, brand, cycle, units
  flags_json TEXT NOT NULL DEFAULT '[]',    -- quote-level warnings from the drafting check
  labour_hours_milli INTEGER NOT NULL DEFAULT 0,
  labour_cost_rate_cents INTEGER NOT NULL DEFAULT 0,
  labour_sell_rate_cents INTEGER NOT NULL DEFAULT 0,
  adjust_cents INTEGER NOT NULL DEFAULT 0,
  valid_days INTEGER NOT NULL DEFAULT 30,
  reviewed_at INTEGER, sent_at INTEGER, closed_at INTEGER,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS quotes_state ON quotes(state, updated_at);
CREATE TABLE IF NOT EXISTS quote_lines(
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  quote_id INTEGER NOT NULL REFERENCES quotes(id) ON DELETE CASCADE,
  position INTEGER NOT NULL,
  sku TEXT,
  description TEXT NOT NULL,
  unit TEXT NOT NULL DEFAULT 'ea',
  qty_milli INTEGER NOT NULL,
  unit_cost_cents INTEGER,                  -- NULL while the line is flagged
  unit_sell_cents INTEGER,
  price_status TEXT NOT NULL DEFAULT 'supplier',   -- placeholder | supplier | manual | none
  flagged INTEGER NOT NULL DEFAULT 0,       -- 1 = no trusted price; left out of every total
  flag_reason TEXT NOT NULL DEFAULT ''
);
CREATE INDEX IF NOT EXISTS lines_quote ON quote_lines(quote_id, position);
CREATE TABLE IF NOT EXISTS events(
  id INTEGER PRIMARY KEY AUTOINCREMENT, quote_id INTEGER, ts INTEGER NOT NULL,
  kind TEXT NOT NULL, detail TEXT NOT NULL DEFAULT '');
"""

DEFAULT_SETTINGS = {
    "business_name": "", "business_abn": "", "business_licence": "", "business_phone": "",
    "business_email": "", "business_address": "",
    "markup_bp": 3000,                 # 30% on materials
    "labour_cost_rate_cents": 6000,    # what an hour costs the business
    "labour_sell_rate_cents": 11000,   # what an hour is charged at, ex GST
    "valid_days": 30,
    "preferred_brands": ["Daikin"],
    "payment_terms": "50% deposit on acceptance, balance on completion. Prices include GST where shown.",
    "quote_footer": "",
}
STATES = ("draft", "sent", "won", "lost")
QUOTE_FIELDS = ("customer_name", "customer_phone", "customer_email", "site_address", "job_title", "scope", "notes")


def now():
    return int(time.time())


class Store:
    def __init__(self, path):
        self.path = path
        os.makedirs(os.path.dirname(os.path.abspath(path)) or ".", exist_ok=True)
        with self.tx() as c:
            c.executescript(SCHEMA)
            if not c.execute("SELECT 1 FROM settings LIMIT 1").fetchone():
                for k, v in DEFAULT_SETTINGS.items():
                    c.execute("INSERT INTO settings VALUES(?,?)", (k, json.dumps(v)))
                c.executemany("INSERT OR IGNORE INTO vendors VALUES(?,?)", SEED_VENDORS)
                for sku, name, cat, brand, vendor, unit, cost, kw in SEED_PARTS:
                    c.execute("INSERT INTO parts(sku,name,category,brand,vendor,unit,cost_cents,kw_milli,price_status,updated_at)"
                              " VALUES(?,?,?,?,?,?,?,?,?,?)",
                              (sku, name, cat, brand, vendor, unit, money.to_cents(cost),
                               money.to_milli(kw) if kw else None, "placeholder", now()))

    @contextmanager
    def tx(self):
        con = sqlite3.connect(self.path, timeout=15)
        con.row_factory = sqlite3.Row
        con.execute("PRAGMA foreign_keys=ON")
        con.execute("PRAGMA journal_mode=WAL")
        try:
            yield con
            con.commit()
        except BaseException:
            con.rollback()
            raise
        finally:
            con.close()

    # ---------------------------------------------------------------- settings and vendors
    def settings(self):
        with self.tx() as c:
            out = dict(DEFAULT_SETTINGS)
            for r in c.execute("SELECT key, value FROM settings"):
                out[r["key"]] = json.loads(r["value"])
            return out

    def save_settings(self, changes):
        clean = {}
        for k, v in changes.items():
            if k not in DEFAULT_SETTINGS:
                raise ValueError("unknown setting: %s" % k)
            want = DEFAULT_SETTINGS[k]
            if isinstance(want, int):
                if isinstance(v, bool) or not isinstance(v, int) or v < 0:
                    raise ValueError("%s must be a whole number, zero or more" % k)
                if k == "valid_days" and not 1 <= v <= 365:
                    raise ValueError("valid_days must be between 1 and 365")
            elif isinstance(want, list):
                if not isinstance(v, list) or not all(isinstance(x, str) for x in v):
                    raise ValueError("%s must be a list of names" % k)
                v = [x.strip()[:60] for x in v if x.strip()][:20]
            else:
                if not isinstance(v, str):
                    raise ValueError("%s must be text" % k)
                v = v.strip()[:600]
            clean[k] = v
        with self.tx() as c:
            for k, v in clean.items():
                c.execute("INSERT INTO settings VALUES(?,?) ON CONFLICT(key) DO UPDATE SET value=excluded.value",
                          (k, json.dumps(v)))
        return self.settings()

    def vendors(self):
        with self.tx() as c:
            return [dict(r) for r in c.execute("SELECT name, discount_bp FROM vendors ORDER BY name COLLATE NOCASE")]

    def save_vendor(self, name, discount_bp):
        name = str(name).strip()[:80]
        if not name:
            raise ValueError("vendor needs a name")
        if isinstance(discount_bp, bool) or not isinstance(discount_bp, int) or not 0 <= discount_bp <= 10000:
            raise ValueError("discount must be between 0% and 100%")
        with self.tx() as c:
            c.execute("INSERT INTO vendors VALUES(?,?) ON CONFLICT(name) DO UPDATE SET discount_bp=excluded.discount_bp",
                      (name, discount_bp))
        return self.vendors()

    # ---------------------------------------------------------------- parts
    def part(self, sku, c=None):
        def get(c):
            r = c.execute("SELECT * FROM parts WHERE sku=? AND active=1", (sku,)).fetchone()
            return dict(r) if r else None
        if c is not None:
            return get(c)
        with self.tx() as c:
            return get(c)

    def search_parts(self, q="", category="", brand="", limit=50, offset=0):
        where, args = ["active=1"], []
        for word in str(q).split()[:6]:
            where.append("(name LIKE ? OR sku LIKE ?)")
            args += ["%" + word + "%"] * 2
        if category:
            where.append("category=?"); args.append(category)
        if brand:
            where.append("brand=?"); args.append(brand)
        limit, offset = max(1, min(int(limit), 200)), max(0, int(offset))
        sql = " FROM parts WHERE " + " AND ".join(where)
        with self.tx() as c:
            total = c.execute("SELECT COUNT(*)" + sql, args).fetchone()[0]
            rows = [dict(r) for r in c.execute("SELECT *" + sql + " ORDER BY category, name COLLATE NOCASE LIMIT ? OFFSET ?",
                                               args + [limit, offset])]
        return {"total": total, "items": rows, "limit": limit, "offset": offset}

    def parts_facets(self):
        with self.tx() as c:
            return {
                "count": c.execute("SELECT COUNT(*) FROM parts WHERE active=1").fetchone()[0],
                "placeholder": c.execute("SELECT COUNT(*) FROM parts WHERE active=1 AND price_status='placeholder'").fetchone()[0],
                "categories": [r[0] for r in c.execute("SELECT DISTINCT category FROM parts WHERE active=1 ORDER BY 1")],
                "brands": [r[0] for r in c.execute("SELECT DISTINCT brand FROM parts WHERE active=1 AND brand<>'' ORDER BY 1")],
            }

    def find_unit(self, category, brand, kw_milli, at_least=False):
        """The library unit for a brand and capacity. at_least picks the smallest that is big enough."""
        with self.tx() as c:
            if at_least:
                r = c.execute("SELECT * FROM parts WHERE active=1 AND category=? AND brand=? COLLATE NOCASE AND kw_milli>=?"
                              " ORDER BY kw_milli LIMIT 1", (category, brand, kw_milli)).fetchone()
            else:
                r = c.execute("SELECT * FROM parts WHERE active=1 AND category=? AND brand=? COLLATE NOCASE AND kw_milli=?"
                              " LIMIT 1", (category, brand, kw_milli)).fetchone()
            return dict(r) if r else None

    def save_part(self, p, status="manual", c=None):
        sku = str(p.get("sku", "")).strip()[:60]
        name = str(p.get("name", "")).strip()[:200]
        if not sku or not name:
            raise ValueError("a part needs a SKU and a name")
        cost = p.get("cost_cents")
        if isinstance(cost, bool) or not isinstance(cost, int) or cost < 0:
            raise ValueError("part %s: cost must be zero or more cents" % sku)
        kw = p.get("kw_milli")
        if kw is not None and (isinstance(kw, bool) or not isinstance(kw, int) or kw <= 0):
            raise ValueError("part %s: kW must be a positive number" % sku)
        row = (sku, name, str(p.get("category", "")).strip()[:40], str(p.get("brand", "")).strip()[:60],
               str(p.get("vendor", "")).strip()[:80], (str(p.get("unit", "")).strip() or "ea")[:12], cost, kw, status, now())

        def put(c):
            c.execute("INSERT INTO parts(sku,name,category,brand,vendor,unit,cost_cents,kw_milli,price_status,updated_at)"
                      " VALUES(?,?,?,?,?,?,?,?,?,?) ON CONFLICT(sku) DO UPDATE SET name=excluded.name,"
                      " category=excluded.category, brand=excluded.brand, vendor=excluded.vendor, unit=excluded.unit,"
                      " cost_cents=excluded.cost_cents, kw_milli=excluded.kw_milli, price_status=excluded.price_status,"
                      " active=1, updated_at=excluded.updated_at", row)
            if row[4]:
                c.execute("INSERT OR IGNORE INTO vendors VALUES(?,0)", (row[4],))
        if c is not None:
            put(c)
        else:
            with self.tx() as c:
                put(c)
        return sku

    def import_parts_csv(self, text):
        """Supplier list as CSV with a header row: sku,name,cost and optionally category,brand,vendor,unit,kw.
        All-or-nothing: one bad row and nothing is imported."""
        reader = csv.DictReader(io.StringIO(text.lstrip("﻿")))
        if not reader.fieldnames:
            raise ValueError("the CSV is empty")
        heads = {h.strip().lower(): h for h in reader.fieldnames if h}
        missing = [h for h in ("sku", "name", "cost") if h not in heads]
        if missing:
            raise ValueError("CSV needs columns sku, name, cost (missing: %s)" % ", ".join(missing))
        get = lambda row, k: (row.get(heads[k]) or "").strip() if k in heads else ""
        n = 0
        with self.tx() as c:
            for i, row in enumerate(reader, start=2):
                if not any((v or "").strip() for v in row.values()):
                    continue
                try:
                    kw = get(row, "kw")
                    self.save_part({"sku": get(row, "sku"), "name": get(row, "name"),
                                    "cost_cents": money.to_cents(get(row, "cost")),
                                    "category": get(row, "category"), "brand": get(row, "brand"),
                                    "vendor": get(row, "vendor"), "unit": get(row, "unit"),
                                    "kw_milli": money.to_milli(kw) if kw else None}, status="supplier", c=c)
                except ValueError as exc:
                    raise ValueError("row %d: %s" % (i, exc))
                n += 1
            if not n:
                raise ValueError("the CSV has no part rows")
        return n

    # ---------------------------------------------------------------- pricing a part for a quote line
    def price_part(self, part, settings=None, c=None):
        """(unit cost after vendor discount, unit sell ex GST) for a library part, right now."""
        settings = settings or self.settings()

        def disc(c):
            r = c.execute("SELECT discount_bp FROM vendors WHERE name=?", (part["vendor"],)).fetchone()
            return r[0] if r else 0
        if c is not None:
            d = disc(c)
        else:
            with self.tx() as c2:
                d = disc(c2)
        cost = money.discounted_cost(part["cost_cents"], d)
        return cost, money.sell_from_cost(cost, settings["markup_bp"])

    # ---------------------------------------------------------------- quotes
    def _next_number(self, c):
        year = time.strftime("%Y")
        r = c.execute("SELECT value FROM settings WHERE key=?", ("seq_" + year,)).fetchone()
        n = (json.loads(r[0]) if r else 0) + 1
        c.execute("INSERT INTO settings VALUES(?,?) ON CONFLICT(key) DO UPDATE SET value=excluded.value",
                  ("seq_" + year, json.dumps(n)))
        return "Q-%s-%04d" % (year, n)

    def create_quote(self, header, lines, source="manual"):
        """header: customer/job fields plus spec, flags, labour_hours_milli. lines: ready-made line dicts."""
        s = self.settings()
        t = now()
        with self.tx() as c:
            number = self._next_number(c)
            cur = c.execute(
                "INSERT INTO quotes(number,state,source,customer_name,customer_phone,customer_email,site_address,job_title,"
                "scope,notes,job_description,spec_json,flags_json,labour_hours_milli,labour_cost_rate_cents,"
                "labour_sell_rate_cents,valid_days,created_at,updated_at) VALUES(?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,?)",
                (number, "draft", source, *[str(header.get(k, ""))[:2000] for k in QUOTE_FIELDS],
                 str(header.get("job_description", ""))[:4000], json.dumps(header.get("spec", {})),
                 json.dumps(header.get("flags", [])), int(header.get("labour_hours_milli", 0)),
                 s["labour_cost_rate_cents"], s["labour_sell_rate_cents"], s["valid_days"], t, t))
            qid = cur.lastrowid
            for i, ln in enumerate(lines):
                self._insert_line(c, qid, i, ln)
            c.execute("INSERT INTO events(quote_id,ts,kind,detail) VALUES(?,?,?,?)", (qid, t, "created", source))
        return qid

    @staticmethod
    def _insert_line(c, qid, position, ln):
        c.execute("INSERT INTO quote_lines(quote_id,position,sku,description,unit,qty_milli,unit_cost_cents,unit_sell_cents,"
                  "price_status,flagged,flag_reason) VALUES(?,?,?,?,?,?,?,?,?,?,?)",
                  (qid, position, ln.get("sku"), str(ln["description"])[:300], ln.get("unit") or "ea", int(ln["qty_milli"]),
                   ln.get("unit_cost_cents"), ln.get("unit_sell_cents"), ln.get("price_status", "supplier"),
                   1 if ln.get("flagged") else 0, str(ln.get("flag_reason", ""))[:300]))

    def quote(self, qid):
        with self.tx() as c:
            r = c.execute("SELECT * FROM quotes WHERE id=?", (qid,)).fetchone()
            if not r:
                return None
            q = dict(r)
            q["spec"] = json.loads(q.pop("spec_json") or "{}")
            q["flags"] = json.loads(q.pop("flags_json") or "[]")
            q["lines"] = [dict(x) for x in c.execute("SELECT * FROM quote_lines WHERE quote_id=? ORDER BY position, id", (qid,))]
        q["totals"] = money.quote_totals(q["lines"], q["labour_hours_milli"], q["labour_cost_rate_cents"],
                                         q["labour_sell_rate_cents"], q["adjust_cents"])
        q["placeholder_lines"] = sum(1 for ln in q["lines"] if not ln["flagged"] and ln["price_status"] == "placeholder")
        return q

    def list_quotes(self, state=""):
        with self.tx() as c:
            ids = [r[0] for r in c.execute(
                "SELECT id FROM quotes" + (" WHERE state=?" if state else "") + " ORDER BY updated_at DESC, id DESC LIMIT 300",
                (state,) if state else ())]
        out = []
        for qid in ids:
            q = self.quote(qid)
            out.append({k: q[k] for k in ("id", "number", "state", "source", "customer_name", "site_address", "job_title",
                                          "updated_at", "created_at", "sent_at", "placeholder_lines")}
                       | {"total_inc_gst_cents": q["totals"]["total_inc_gst_cents"],
                          "total_ex_gst_cents": q["totals"]["total_ex_gst_cents"],
                          "flagged_lines": q["totals"]["unpriced_lines"]})
        return out

    def _draft(self, c, qid):
        r = c.execute("SELECT state FROM quotes WHERE id=?", (qid,)).fetchone()
        if not r:
            raise LookupError("no such quote")
        if r["state"] != "draft":
            raise PermissionError("this quote has been sent. Reopen it as a draft to change it.")

    def _touch(self, c, qid):
        # any change to a draft means it has to be reviewed again before it can be sent
        c.execute("UPDATE quotes SET updated_at=?, reviewed_at=NULL WHERE id=?", (now(), qid))

    def update_quote(self, qid, changes):
        sets, args = [], []
        for k, v in changes.items():
            if k in QUOTE_FIELDS:
                sets.append(k + "=?"); args.append(str(v)[:2000])
            elif k in ("labour_hours_milli", "labour_cost_rate_cents", "labour_sell_rate_cents"):
                if isinstance(v, bool) or not isinstance(v, int) or v < 0:
                    raise ValueError("%s must be zero or more" % k)
                sets.append(k + "=?"); args.append(v)
            elif k == "adjust_cents":
                if isinstance(v, bool) or not isinstance(v, int):
                    raise ValueError("adjustment must be a whole number of cents")
                sets.append(k + "=?"); args.append(v)
            elif k == "valid_days":
                if isinstance(v, bool) or not isinstance(v, int) or not 1 <= v <= 365:
                    raise ValueError("valid_days must be between 1 and 365")
                sets.append(k + "=?"); args.append(v)
            else:
                raise ValueError("cannot change %s" % k)
        with self.tx() as c:
            self._draft(c, qid)
            if sets:
                c.execute("UPDATE quotes SET %s WHERE id=?" % ", ".join(sets), args + [qid])
            self._touch(c, qid)
        q = self.quote(qid)          # raises if the adjustment drives the total below zero
        return q

    def add_line(self, qid, ln):
        with self.tx() as c:
            self._draft(c, qid)
            pos = c.execute("SELECT COALESCE(MAX(position),-1)+1 FROM quote_lines WHERE quote_id=?", (qid,)).fetchone()[0]
            self._insert_line(c, qid, pos, ln)
            self._touch(c, qid)
        return self.quote(qid)

    def update_line(self, qid, lid, changes):
        with self.tx() as c:
            self._draft(c, qid)
            if not c.execute("SELECT 1 FROM quote_lines WHERE id=? AND quote_id=?", (lid, qid)).fetchone():
                raise LookupError("no such line")
            sets, args = [], []
            for k, v in changes.items():
                if k not in ("sku", "description", "unit", "qty_milli", "unit_cost_cents", "unit_sell_cents",
                             "price_status", "flagged", "flag_reason"):
                    raise ValueError("cannot change %s" % k)
                sets.append(k + "=?"); args.append(v)
            if sets:
                c.execute("UPDATE quote_lines SET %s WHERE id=?" % ", ".join(sets), args + [lid])
            self._touch(c, qid)
        return self.quote(qid)

    def delete_line(self, qid, lid):
        with self.tx() as c:
            self._draft(c, qid)
            c.execute("DELETE FROM quote_lines WHERE id=? AND quote_id=?", (lid, qid))
            self._touch(c, qid)
        return self.quote(qid)

    def clear_flags(self, qid):
        with self.tx() as c:
            self._draft(c, qid)
            c.execute("UPDATE quotes SET flags_json='[]' WHERE id=?", (qid,))
            self._touch(c, qid)
        return self.quote(qid)

    def send(self, qid, reviewed, prices_checked):
        """The only way out of DRAFT. A person must have reviewed it; nothing unpriced may remain."""
        q = self.quote(qid)
        if not q:
            raise LookupError("no such quote")
        if q["state"] != "draft":
            raise PermissionError("only a draft can be sent")
        if reviewed is not True:
            raise PermissionError("a person must review the quote before it is sent")
        if q["totals"]["unpriced_lines"]:
            raise ValueError("%d line(s) have no trusted price. Pick a part or set a price first." % q["totals"]["unpriced_lines"])
        if q["flags"]:
            raise ValueError("clear the %d drafting warning(s) first" % len(q["flags"]))
        if not q["lines"] and not q["labour_hours_milli"]:
            raise ValueError("the quote is empty")
        if q["placeholder_lines"] and prices_checked is not True:
            raise ValueError("%d line(s) use placeholder prices. Confirm you have checked them." % q["placeholder_lines"])
        if not q["customer_name"].strip():
            raise ValueError("add the customer's name first")
        t = now()
        with self.tx() as c:
            c.execute("UPDATE quotes SET state='sent', reviewed_at=?, sent_at=?, updated_at=? WHERE id=? AND state='draft'",
                      (t, t, t, qid))
            c.execute("INSERT INTO events(quote_id,ts,kind,detail) VALUES(?,?,?,?)", (qid, t, "sent", "reviewed by a person"))
        return self.quote(qid)

    def set_state(self, qid, state):
        if state not in ("draft", "won", "lost"):
            raise ValueError("state must be draft, won or lost")
        t = now()
        with self.tx() as c:
            r = c.execute("SELECT state FROM quotes WHERE id=?", (qid,)).fetchone()
            if not r:
                raise LookupError("no such quote")
            if state in ("won", "lost") and r["state"] == "draft":
                raise PermissionError("send the quote before marking it won or lost")
            if state == "draft":      # reopening always clears the review
                c.execute("UPDATE quotes SET state='draft', reviewed_at=NULL, sent_at=NULL, closed_at=NULL, updated_at=? WHERE id=?",
                          (t, qid))
            else:
                c.execute("UPDATE quotes SET state=?, closed_at=?, updated_at=? WHERE id=?", (state, t, t, qid))
            c.execute("INSERT INTO events(quote_id,ts,kind,detail) VALUES(?,?,?,?)", (qid, t, state, ""))
        return self.quote(qid)

    def delete_quote(self, qid):
        with self.tx() as c:
            self._draft(c, qid)
            c.execute("DELETE FROM quotes WHERE id=?", (qid,))

    # ---------------------------------------------------------------- pipeline (for the Jarvis panel)
    def pipeline(self):
        quotes = self.list_quotes()
        states = {s: {"count": 0, "total_inc_gst_cents": 0} for s in STATES}
        for q in quotes:
            states[q["state"]]["count"] += 1
            states[q["state"]]["total_inc_gst_cents"] += q["total_inc_gst_cents"]
        closed = states["won"]["count"] + states["lost"]["count"]
        with self.tx() as c:
            events = [dict(r) for r in c.execute(
                "SELECT e.ts, e.kind, e.detail, q.number, q.customer_name, q.id AS quote_id FROM events e"
                " LEFT JOIN quotes q ON q.id=e.quote_id ORDER BY e.id DESC LIMIT 12")]
        return {"states": states, "win_rate_bp": money.margin_bp(states["won"]["count"], closed) if closed else None,
                "needs_attention": [q for q in quotes if q["state"] == "draft" and (q["flagged_lines"] or q["placeholder_lines"])][:8],
                "recent": events}

"""Turning a job into a draft quote.

Three steps, and only the first may involve an AI:
  1. understand(): read the tradie's words into a small spec (install type, brand, kW, customer).
     Done by a local rule-based reader, or by an OpenAI-compatible model when one is configured.
  2. build_lines(): fixed install recipes turn the spec into line items. Every price is read
     from the parts library. Nothing here asks an AI for a number.
  3. check_ai_items() / scrub_notes(): anything else the model proposed is checked against the
     library. An item that is not in the library is kept as a flagged line with NO price, and
     any dollar figure the model wrote that the library cannot account for is removed and
     reported. A fabricated price is a failure, so it is never shown.
"""
import json
import math
import re
import urllib.error
import urllib.request

from . import money

INSTALL_TYPES = ("single_split", "multi_split", "ducted", "service")
INSTALL_LABEL = {"single_split": "Split system", "multi_split": "Multi-split system",
                 "ducted": "Ducted system", "service": "Service and maintenance"}

_WORDS = {"zero": 0, "one": 1, "two": 2, "three": 3, "four": 4, "five": 5, "six": 6, "seven": 7, "eight": 8,
          "nine": 9, "ten": 10, "eleven": 11, "twelve": 12, "thirteen": 13, "fourteen": 14, "fifteen": 15,
          "sixteen": 16, "seventeen": 17, "eighteen": 18, "nineteen": 19, "twenty": 20}
_NUM = "|".join(sorted(_WORDS, key=len, reverse=True))
_WORD_NUMBER = re.compile(
    r"\b(%s|\d+)(?:\s+and\s+a\s+(half)|\s+point\s+(%s|\d+))?\b" % (_NUM, _NUM))
_KW = re.compile(r"(?:\b(\d{1,2})\s*(?:x|×|by|of|lots? of)?\s+)?(\d{1,2}(?:\.\d{1,2})?)\s*(?:kw|kilowatts?|k\.w\.?)\b")
_NOT_NAMES = {"the", "a", "this", "that", "install", "split", "ducted", "new", "next", "big", "small", "same",
              "another", "one", "quick", "easy", "little", "service", "my", "our", "his", "her", "their",
              "back", "to", "standard", "simple", "straightforward", "multi", "system", "unit", "kw", "wall", "roof"}
# brands a tradie might say that the library may not stock yet: recognised, so they are never
# silently swapped for the preferred brand
KNOWN_BRANDS = ("Daikin", "Mitsubishi Electric", "Mitsubishi Heavy Industries", "Fujitsu", "Samsung", "Panasonic",
                "LG", "Hitachi", "Toshiba", "Carrier", "Kelvinator", "Gree", "Haier", "Hisense", "Midea", "TCL",
                "ActronAir", "Rinnai", "Braemar", "Bonaire", "Temperzone")
BRAND_ALIASES = {"mitsi": "Mitsubishi Electric", "mitsubishi": "Mitsubishi Electric", "mhi": "Mitsubishi Heavy Industries",
                 "actron": "ActronAir"}


def words_to_numbers(text):
    """'two and a half kw' -> '2.5 kw'; 'seven point one' -> '7.1'. Plain digits pass through."""
    def swap(m):
        whole = _WORDS.get(m.group(1), None)
        whole = int(m.group(1)) if whole is None else whole
        if m.group(2):
            return "%d.5" % whole
        if m.group(3) is not None:
            frac = _WORDS.get(m.group(3))
            return "%d.%s" % (whole, m.group(3) if frac is None else frac)
        return str(whole) if m.group(1) in _WORDS else m.group(0)
    return _WORD_NUMBER.sub(swap, text)


def understand_locally(job, brands, preferred_brands=()):
    """Rule-based reading of a job description. Returns a spec dict and a list of warnings."""
    text = words_to_numbers(" ".join(str(job).lower().split()))
    flags = []

    units = []
    for m in _KW.finditer(text):
        count = min(int(m.group(1)), 8) if m.group(1) else 1
        try:
            kw = money.to_milli(m.group(2))
        except ValueError:
            continue
        if 500 <= kw <= 30000:
            units += [{"kw_milli": kw}] * max(count, 1)

    if re.search(r"\bducted\b", text):
        kind = "ducted"
    elif re.search(r"\b(service|servicing|clean|maintenance)\b", text) and not units:
        kind = "service"
    elif re.search(r"\bmulti\b", text) or len(units) > 1:
        kind = "multi_split"
    elif units or re.search(r"\bsplit\b", text):
        kind = "single_split"
    else:
        kind = "single_split"
        flags.append("Could not tell the installation type from the description. Assumed a split system.")

    brand = ""
    for name in sorted(set(brands) | set(KNOWN_BRANDS), key=len, reverse=True):
        if name and re.search(r"\b%s\b" % re.escape(name.lower()), text):
            brand = name
            break
    if not brand:
        for alias, name in BRAND_ALIASES.items():
            if re.search(r"\b%s\b" % alias, text) and not (alias == "mitsubishi" and "heavy" in text):
                brand = name
                break
    if not brand and kind != "service":
        brand = (list(preferred_brands) or [""])[0]
        flags.append("No brand was mentioned. Used your preferred brand%s." % (" (" + brand + ")" if brand else ""))

    if kind != "service" and not units:
        flags.append("No capacity (kW) was mentioned. Add the unit yourself.")
    if kind == "service":
        m = re.search(r"\b(\d{1,2})\s+(?:units?|systems?|splits?|heads?)\b", text)
        units = [{"kw_milli": 0}] * (min(int(m.group(1)), 20) if m else 1)

    customer = ""
    found = list(re.finditer(r"\b(?:mr|mrs|ms|miss|dr)\.?\s+([a-z][a-z']+)", text)) + \
        list(re.finditer(r"\b([a-z][a-z']+?)(?:'s)?\s+(?:job|place|house|residence)\b", text))
    for m in found:
        word = m.group(1).strip("'")
        if word not in _NOT_NAMES and word not in _WORDS and len(word) > 1:
            customer = word.title()
            break

    spec = {"install_type": kind, "brand": brand,
            "cycle": "cooling_only" if re.search(r"\bcooling[\s-]*only\b", text) else "reverse_cycle",
            "units": units,
            "back_to_back": bool(re.search(r"\bback[\s-]*(?:to|2)[\s-]*back\b", text)),
            "wall_bracket": bool(re.search(r"\bbrackets?\b", text)),
            "customer_name": customer}
    return spec, flags


def clean_spec(raw, brands=()):
    """Force any spec (from the form, the local reader or a model) into the one shape recipes accept."""
    kind = raw.get("install_type")
    if kind not in INSTALL_TYPES:
        raise ValueError("install type must be one of: %s" % ", ".join(INSTALL_TYPES))
    units = []
    for u in (raw.get("units") or [])[:12]:
        kw = u.get("kw_milli") if isinstance(u, dict) else None
        if kw is None and isinstance(u, dict) and u.get("kw") is not None:
            kw = money.to_milli(u["kw"])
        if isinstance(kw, bool) or not isinstance(kw, int) or not 0 <= kw <= 30000:
            raise ValueError("unit capacity must be between 0 and 30 kW")
        count = u.get("count", 1) if isinstance(u, dict) else 1
        count = count if isinstance(count, int) and not isinstance(count, bool) else 1
        units += [{"kw_milli": kw, "room": str(u.get("room", ""))[:40]}] * max(1, min(count, 12))
    brand = str(raw.get("brand") or "").strip()[:60]
    for b in brands:                      # use the library's own spelling of the brand
        if b.lower() == brand.lower():
            brand = b
    return {"install_type": kind, "brand": brand,
            "cycle": "cooling_only" if raw.get("cycle") == "cooling_only" else "reverse_cycle",
            "units": units[:12], "back_to_back": bool(raw.get("back_to_back")),
            "wall_bracket": bool(raw.get("wall_bracket")),
            "customer_name": str(raw.get("customer_name") or "").strip()[:80]}


def _kw(kw_milli):
    return money.fmt_qty(kw_milli) + ("" if kw_milli % 1000 else ".0")


def recipe(spec):
    """The install recipe: what a job of this shape normally needs.
    Returns (items, labour_hours_milli). An item is (category-or-sku lookup, qty_milli)."""
    kind, units, items = spec["install_type"], spec["units"], []
    n = len(units)

    def part(sku, qty):
        items.append({"sku": sku, "qty_milli": int(qty * 1000)})

    def unit(category, kw, at_least=False, label=""):
        items.append({"unit": category, "kw_milli": kw, "at_least": at_least, "qty_milli": 1000, "label": label})

    def pipe(kw, metres):
        part("PIPE-PAIR-6-10" if kw <= 3500 else "PIPE-PAIR-6-12" if kw <= 5000 else "PIPE-PAIR-10-16", metres)

    if kind == "single_split":
        run = 3 if spec["back_to_back"] else 6
        for u in units:
            unit("unit-split", u["kw_milli"], label="wall split system (package)")
            pipe(u["kw_milli"], run)
            part("ELEC-INTER-15", run)
            part("TRK-80-2M", 1 if spec["back_to_back"] else math.ceil(run / 2))
            part("DRN-PVC-20", 3)
        k = max(n, 1)
        part("ELEC-ISO-20", k); part("ELEC-CB-20", k); part("ELEC-TPS-25", 10 * k)
        part("MNT-BRKT" if spec["wall_bracket"] else "MNT-SLAB", k)
        part("CON-SUNDRY", 1)
        return items, (4000 if spec["back_to_back"] else 6000) * k
    if kind == "multi_split":
        total = sum(u["kw_milli"] for u in units)
        unit("unit-multi-outdoor", total, at_least=True, label="multi-split outdoor unit")
        for u in units:
            unit("unit-multi-indoor", u["kw_milli"], label="multi-split indoor wall unit")
            pipe(u["kw_milli"], 8)
            part("ELEC-INTER-15", 8); part("TRK-80-2M", 2); part("DRN-PVC-20", 3)
        part("ELEC-ISO-20", 1); part("ELEC-CB-20", 1); part("ELEC-TPS-25", 12)
        part("MNT-BRKT" if spec["wall_bracket"] else "MNT-SLAB", 1)
        part("CON-SUNDRY", 1)
        return items, 5000 + 3000 * n
    if kind == "ducted":
        for u in units[:1]:
            unit("unit-ducted", u["kw_milli"], label="ducted system (package)")
        outlets, zones = 6, 2
        part("DCT-PLENUM", 1); part("DCT-FLEX-300", 2); part("DCT-FLEX-250", math.ceil(outlets / 2))
        part("DCT-DIFF", outlets); part("DCT-RAG", 1); part("DCT-DAMPER", zones); part("CTL-ZONE", 1)
        part("PIPE-PAIR-10-16", 10); part("ELEC-INTER-15", 10)
        part("ELEC-ISO-20", 1); part("ELEC-CB-20", 1); part("ELEC-TPS-25", 15)
        part("MNT-SLAB", 1); part("DRN-PVC-20", 6); part("CON-SUNDRY", 1)
        return items, 16000
    part("SVC-CALLOUT", 1)
    part("SVC-KIT", max(n, 1))
    return items, 1000 * max(n, 1)


def flagged_line(description, reason, qty_milli=1000, unit="ea"):
    return {"sku": None, "description": description[:300], "unit": unit, "qty_milli": qty_milli,
            "unit_cost_cents": None, "unit_sell_cents": None, "price_status": "none",
            "flagged": True, "flag_reason": reason}


def library_line(store, part, qty_milli, settings=None):
    cost, sell = store.price_part(part, settings)
    return {"sku": part["sku"], "description": part["name"], "unit": part["unit"], "qty_milli": qty_milli,
            "unit_cost_cents": cost, "unit_sell_cents": sell, "price_status": part["price_status"],
            "flagged": False, "flag_reason": ""}


def build_lines(store, spec):
    """Spec -> priced lines, straight from the library. Returns (lines, labour_hours_milli, title, scope)."""
    settings = store.settings()
    items, labour = recipe(spec)
    merged, order = {}, []
    lines = []
    for it in items:
        if "unit" in it:
            part = store.find_unit(it["unit"], spec["brand"], it["kw_milli"], it["at_least"]) if spec["brand"] else None
            if part:
                lines.append(library_line(store, part, it["qty_milli"], settings))
            else:
                what = ("%s %skW %s" % (spec["brand"] or "Unbranded", _kw(it["kw_milli"]), it["label"])).strip()
                lines.append(flagged_line(what, "Not in the parts library. Pick a part or set the price yourself."))

        part = store.part(sku)

    sizes = ", ".join("%skW" % _kw(u["kw_milli"]) for u in spec["units"] if u["kw_milli"])
    brand = (spec["brand"] + " ") if spec["brand"] else ""

# ---------------------------------------------------------------- the fabrication check

_PRICE = re.compile(r"(?:(?:\b(?:aud|au)\s?)?\$\s?\d[\d,]*(?:\.\d{1,2})?(?:\s?k\b)?|\b\d[\d,]*(?:\.\d{1,2})?\s?(?:dollars|bucks)\b)", re.I)


def _figure_cents(text):
    digits = re.sub(r"[^\d.,k]", "", text.lower())
    thousand = digits.endswith("k")
    try:
        cents = money.to_cents(digits.rstrip("k"))
    except ValueError:
        return None
    return cents * 1000 if thousand else cents


def scrub_notes(text, allowed_cents=()):
    """Remove every dollar figure the library cannot account for. Returns (clean text, figures removed)."""
    allowed, removed = set(allowed_cents), []

    def swap(m):
        cents = _figure_cents(m.group(0))
        if cents is not None and cents in allowed:
            return m.group(0)
        removed.append(m.group(0).strip())
        return "[price removed]"
    return _PRICE.sub(swap, str(text)), removed


def check_ai_items(store, items):
    """Vet line items proposed by a model. Returns (lines, flags).
    In the library -> priced from the library (the model's own number is discarded).
    Not in the library -> kept as a flagged line with no price."""
    lines, flags = [], []
    settings = store.settings()
    for it in (items or [])[:40]:
        if not isinstance(it, dict):
            continue
        desc = " ".join(str(it.get("description") or it.get("name") or "").split())[:200]
        try:
            qty = money.to_milli(it.get("qty", it.get("quantity", 1)) or 1)
        except ValueError:
            qty = 1000
        qty = qty if 0 < qty <= 10_000_000 else 1000
        offered = next((it[k] for k in ("unit_price", "price", "unit_price_cents", "cost", "total") if it.get(k) not in (None, "")), None)
        part = store.part(str(it.get("sku") or "").strip()) if it.get("sku") else None
        if part:
            lines.append(library_line(store, part, qty, settings))
            if offered is not None:
                flags.append("The AI suggested its own price for %s. It was discarded; the library price is used." % part["name"])
        elif desc:
            reason = "Suggested by the AI but not in the parts library, so it has no price."
            if offered is not None:
                reason = "The AI gave a price for this item that is not in the parts library. The price was not shown."
            lines.append(flagged_line(desc, reason, qty, str(it.get("unit") or "ea")[:12]))
    return lines, flags

"""All money maths for the app. Plain functions, integer cents, no AI, no floats.

Rules
  * Money is an int number of cents. Quantities are an int number of thousandths
    (2.5 m of pipe = 2500), so nothing here ever touches binary floating point.
  * Percentages are basis points (10% = 1000 bp).
  * Every rounding is half-up to the nearest cent, done once, at the point named.
  * GST is 10% of the ex-GST total, rounded once on the total (not per line).
"""
from decimal import Decimal, ROUND_HALF_UP, InvalidOperation

GST_BP = 1000  # Australian GST, 10%


def _round(d):
    return int(Decimal(d).quantize(Decimal(1), rounding=ROUND_HALF_UP))


def _int(name, v, minimum=None):
    if isinstance(v, bool) or not isinstance(v, int):
        raise ValueError("%s must be a whole number, got %r" % (name, v))
    if minimum is not None and v < minimum:
        raise ValueError("%s must be at least %d, got %d" % (name, minimum, v))
    return v


def to_cents(value):
    """'12.345' / 12 / '1,200.50' / '$80' -> cents, half-up. Refuses floats' hidden error by going via str."""
    try:
        d = Decimal(str(value).replace(",", "").replace("$", "").strip())
    except (InvalidOperation, ValueError):
        raise ValueError("not a dollar amount: %r" % (value,))
    if not d.is_finite():
        raise ValueError("not a dollar amount: %r" % (value,))
    return _round(d * 100)


def to_milli(value):
    """'2.5' -> 2500 (a quantity in thousandths)."""
    try:
        d = Decimal(str(value).replace(",", "").strip())
    except (InvalidOperation, ValueError):
        raise ValueError("not a quantity: %r" % (value,))
    if not d.is_finite() or d < 0:
        raise ValueError("not a quantity: %r" % (value,))
    return _round(d * 1000)


def to_bp(percent):
    """'12.5' (percent) -> 1250 basis points."""
    try:
        d = Decimal(str(percent).replace("%", "").strip())
    except (InvalidOperation, ValueError):
        raise ValueError("not a percentage: %r" % (percent,))
    if not d.is_finite():
        raise ValueError("not a percentage: %r" % (percent,))
    return _round(d * 100)


def discounted_cost(list_cost_cents, discount_bp):
    """Supplier list cost less the vendor discount = what the part really costs us."""
    _int("list cost", list_cost_cents, 0)
    _int("discount", discount_bp, 0)
    if discount_bp > 10000:
        raise ValueError("discount cannot exceed 100%")
    return _round(Decimal(list_cost_cents) * (10000 - discount_bp) / 10000)


def sell_from_cost(cost_cents, markup_bp):
    """Our cost plus markup = the unit sell price, ex GST."""
    _int("cost", cost_cents, 0)
    _int("markup", markup_bp, 0)
    return _round(Decimal(cost_cents) * (10000 + markup_bp) / 10000)


def extend(unit_cents, qty_milli):
    """Unit price x quantity, rounded once."""
    _int("unit price", unit_cents, 0)
    _int("quantity", qty_milli, 0)
    return _round(Decimal(unit_cents) * qty_milli / 1000)


def gst_on(ex_cents):
    return _round(Decimal(_int("ex-GST amount", ex_cents)) * GST_BP / 10000)


def margin_bp(profit_cents, sell_ex_cents):
    """Net profit as a share of the ex-GST sell price, in basis points. 0 when nothing is sold."""
    if sell_ex_cents <= 0:
        return 0
    return _round(Decimal(profit_cents) * 10000 / sell_ex_cents)


def quote_totals(lines, labour_hours_milli=0, labour_cost_rate_cents=0, labour_sell_rate_cents=0, adjust_cents=0):
    """The whole quote, to the cent.

    lines: dicts with qty_milli, unit_cost_cents, unit_sell_cents and optionally flagged.
    A flagged line, or one with no price, is left out of every total and counted in `unpriced`.
    adjust_cents is the human's own adjustment to the price (may be negative).
    """
    _int("labour hours", labour_hours_milli, 0)
    _int("labour cost rate", labour_cost_rate_cents, 0)
    _int("labour sell rate", labour_sell_rate_cents, 0)
    _int("adjustment", adjust_cents)
    external = materials_sell = unpriced = 0
    for ln in lines:
        if ln.get("flagged") or ln.get("unit_sell_cents") is None or ln.get("unit_cost_cents") is None:
            unpriced += 1
            continue
        external += extend(ln["unit_cost_cents"], ln["qty_milli"])
        materials_sell += extend(ln["unit_sell_cents"], ln["qty_milli"])
    labour_cost = extend(labour_cost_rate_cents, labour_hours_milli)
    labour_sell = extend(labour_sell_rate_cents, labour_hours_milli)
    ex = materials_sell + labour_sell + adjust_cents
    if ex < 0:
        raise ValueError("adjustment would make the quote negative")
    gst = gst_on(ex)
    profit = ex - external - labour_cost
    return {
        "external_cost_cents": external,
        "labour_cost_cents": labour_cost,
        "materials_sell_cents": materials_sell,
        "labour_sell_cents": labour_sell,
        "adjust_cents": adjust_cents,
        "total_ex_gst_cents": ex,
        "gst_cents": gst,
        "total_inc_gst_cents": ex + gst,
        "net_profit_cents": profit,
        "margin_bp": margin_bp(profit, ex),
        "unpriced_lines": unpriced,
    }


def fmt_money(cents):
    """123456 -> '$1,234.56'; negatives as '-$5.00'."""
    _int("amount", cents)
    sign = "-" if cents < 0 else ""
    cents = abs(cents)
    return "%s$%s.%02d" % (sign, format(cents // 100, ","), cents % 100)


def fmt_qty(qty_milli):
    """2500 -> '2.5', 3000 -> '3'."""
    whole, frac = divmod(_int("quantity", qty_milli, 0), 1000)
    return str(whole) if not frac else ("%d.%03d" % (whole, frac)).rstrip("0")


def fmt_percent(bp):
    """2074 -> '20.74%'."""
    sign = "-" if bp < 0 else ""
    bp = abs(bp)
    return "%s%d.%02d%%" % (sign, bp // 100, bp % 100)

def _enc(text):
    return str(text).replace("—", "-").replace("–", "-").encode("cp1252", "replace")


def text_width(text, size, bold=False):
    table = _WB if bold else _W
    return sum(table[b - 32] if 32 <= b <= 126 else 556 for b in _enc(text)) * size / 1000.0


def wrap(text, size, width, bold=False):
    out = []
    for para in str(text).replace("\r", "").split("\n"):
        line = ""
        for word in para.split():
            trial = (line + " " + word).strip()
            if line and text_width(trial, size, bold) > width:
                out.append(line)
                line = word
            else:
                line = trial
            while text_width(line, size, bold) > width and len(line) > 1:      # one very long word
                cut = len(line) - 1
                while cut > 1 and text_width(line[:cut], size, bold) > width:
                    cut -= 1
                out.append(line[:cut])
                line = line[cut:]
        out.append(line)
    return out or [""]


def jpeg_size(data):
    """(width, height, components) of a JPEG, read from its frame header."""
    if data[:2] != b"\xff\xd8":
        raise ValueError("not a JPEG")
    i = 2
    while i + 9 < len(data):
        if data[i] != 0xFF:
            i += 1
            continue
        marker = data[i + 1]
        if marker in (0xC0, 0xC1, 0xC2):
            return (int.from_bytes(data[i + 7:i + 9], "big"), int.from_bytes(data[i + 5:i + 7], "big"), data[i + 9])
        if marker in (0xD8, 0x01) or 0xD0 <= marker <= 0xD7:
            i += 2
            continue
        i += 2 + int.from_bytes(data[i + 2:i + 4], "big")
    raise ValueError("JPEG has no frame header")


class Document:
    """Pages are drawn top-down: y is the distance from the top edge, in points."""

    def __init__(self, title="", author=""):
        self.pages, self.image, self.title, self.author = [], None, title, author
        self.w, self.h = A4

    def add_page(self):
        self.pages.append([])

    def _put(self, s):
        self.pages[-1].append(s if isinstance(s, bytes) else s.encode("latin-1"))

    def rect(self, x, y, w, h, rgb):
        self._put("%.3f %.3f %.3f rg %.2f %.2f %.2f %.2f re f\n" % (*rgb, x, self.h - y - h, w, h))

    def line(self, x1, y1, x2, y2, rgb=(0.8, 0.8, 0.8), width=0.6):
        self._put("%.3f %.3f %.3f RG %.2f w %.2f %.2f m %.2f %.2f l S\n" % (*rgb, width, x1, self.h - y1, x2, self.h - y2))

    def text(self, x, y, s, size=10, bold=False, rgb=(0.1, 0.1, 0.12), align="left"):
        """y is the baseline. align right/center positions the text against x."""
        if align != "left":
            w = text_width(s, size, bold)
            x -= w if align == "right" else w / 2
        raw = _enc(s).replace(b"\\", b"\\\\").replace(b"(", b"\\(").replace(b")", b"\\)")
        self._put(b"BT /F%d %.2f Tf %.3f %.3f %.3f rg %.2f %.2f Td (" % (2 if bold else 1, size, *rgb, x, self.h - y)
                  + raw + b") Tj ET\n")

    def watermark(self, s, size=120, rgb=(0.93, 0.93, 0.95)):
        c = 0.7071
        raw = _enc(s)
        self._put(b"q %.4f %.4f %.4f %.4f %.2f %.2f cm BT /F2 %d Tf %.3f %.3f %.3f rg 0 0 Td (" % (
            c, c, -c, c, self.w / 2 - 190, self.h / 2 - 250, size, *rgb) + raw + b") Tj ET Q\n")

    def set_image(self, jpeg):
        self.image = (jpeg,) + jpeg_size(jpeg)

    def draw_image(self, x, y, w, h):
        if self.image:
            self._put("q %.2f 0 0 %.2f %.2f %.2f cm /Im1 Do Q\n" % (w, h, x, self.h - y - h))

    def build(self):
        objs = []                                   # object n is objs[n-1]

        def add(body):
            objs.append(body if isinstance(body, bytes) else body.encode("latin-1"))
            return len(objs)

        add(b"")                                    # 1 catalog (filled in below)
        add(b"")                                    # 2 pages
        f1 = add("<< /Type /Font /Subtype /Type1 /BaseFont /Helvetica /Encoding /WinAnsiEncoding >>")
        f2 = add("<< /Type /Font /Subtype /Type1 /BaseFont /Helvetica-Bold /Encoding /WinAnsiEncoding >>")
        resources = "/Font << /F1 %d 0 R /F2 %d 0 R >>" % (f1, f2)
        if self.image:
            data, iw, ih, comps = self.image
            im = add(b"<< /Type /XObject /Subtype /Image /Width %d /Height %d /ColorSpace /%s /BitsPerComponent 8 "
                     b"/Filter /DCTDecode /Length %d >>\nstream\n" % (
                         iw, ih, b"DeviceRGB" if comps == 3 else b"DeviceGray" if comps == 1 else b"DeviceCMYK",
                         len(data)) + data + b"\nendstream")
            resources += " /XObject << /Im1 %d 0 R >>" % im
        kids = []
        for content in self.pages:
            stream = zlib.compress(b"".join(content))
            c = add(b"<< /Length %d /Filter /FlateDecode >>\nstream\n" % len(stream) + stream + b"\nendstream")
            kids.append(add("<< /Type /Page /Parent 2 0 R /MediaBox [0 0 %.2f %.2f] /Resources << %s >> /Contents %d 0 R >>"
                            % (self.w, self.h, resources, c)))
        objs[0] = b"<< /Type /Catalog /Pages 2 0 R >>"
        objs[1] = ("<< /Type /Pages /Count %d /Kids [%s] >>" % (len(kids), " ".join("%d 0 R" % k for k in kids))).encode()
        esc = lambda t: _enc(t).replace(b"\\", b"\\\\").replace(b"(", b"\\(").replace(b")", b"\\)")
        info = add(b"<< /Title (" + esc(self.title) + b") /Author (" + esc(self.author) + b") /Producer (The 48 - AI's Best Mate) >>")

        out = bytearray(b"%PDF-1.4\n%\xe2\xe3\xcf\xd3\n")
        offsets = []
        for n, body in enumerate(objs, start=1):
            offsets.append(len(out))
            out += b"%d 0 obj\n" % n + body + b"\nendobj\n"
        xref = len(out)
        out += b"xref\n0 %d\n0000000000 65535 f \n" % (len(objs) + 1)
        for off in offsets:
            out += b"%010d 00000 n \n" % off
        out += b"trailer\n<< /Size %d /Root 1 0 R /Info %d 0 R >>\nstartxref\n%d\n%%%%EOF\n" % (len(objs) + 1, info, xref)
        return bytes(out)

"""Voice. The contract the rest of the app builds against:

    POST /api/voice/speak   {"text": "..."}      -> audio/wav
    POST /api/voice/listen  <audio bytes>        -> {"text": "..."}

With VOICE_BASE_URL unset this is a local stub: speak returns a short chime (a real WAV, so the
player code is exercised) and listen returns a fixed sentence marked as a stub. With it set, both
calls are passed straight through to the same two paths on that server, which is where the
Pocket TTS "Jane" voice plugs in. No cloud voice key is used or stored anywhere.
"""
import io
import json
import math
import struct
import urllib.request
import wave

STUB_SENTENCE = "two and a half kW Daikin split, back-to-back install, Smith job"


def chime(seconds=0.42, rate=16000):
    """Two soft rising tones. Stands in for Jane until her voice server is connected."""
    frames = bytearray()
    total = int(seconds * rate)
    for i in range(total):
        t = i / rate
        freq = 660.0 if i < total // 2 else 880.0
        fade = min(1.0, i / 400.0, (total - i) / 2400.0)
        frames += struct.pack("<h", int(9000 * fade * math.sin(2 * math.pi * freq * t)))
    buf = io.BytesIO()
    with wave.open(buf, "wb") as w:
        w.setnchannels(1); w.setsampwidth(2); w.setframerate(rate)
        w.writeframes(bytes(frames))
    return buf.getvalue()


def _post(url, data, content_type, key, timeout):
    headers = {"Content-Type": content_type}
    if key:
        headers["Authorization"] = "Bearer " + key
    with urllib.request.urlopen(urllib.request.Request(url, data=data, headers=headers), timeout=timeout) as r:
        return r.read(), r.headers.get("Content-Type", "")


def speak(text, cfg, timeout=30):
    """-> (wav bytes, mode) where mode is 'stub' or 'live'."""
    text = " ".join(str(text or "").split())[:1200]
    if not text:
        raise ValueError("nothing to say")
    if not cfg.get("voice_base_url"):
        return chime(), "stub"
    audio, _ = _post(cfg["voice_base_url"].rstrip("/") + "/api/voice/speak",
                     json.dumps({"text": text, "voice": cfg.get("voice_name") or "jane"}).encode(),
                     "application/json", cfg.get("voice_key"), timeout)
    if not audio.startswith(b"RIFF"):
        raise ValueError("the voice server did not return WAV audio")
    return audio, "live"


def listen(audio, content_type, cfg, timeout=60):
    """-> {"text": ..., "stub": bool}"""
    if not cfg.get("voice_base_url"):
        return {"text": cfg.get("voice_stub_text") or STUB_SENTENCE, "stub": True}
    if not audio:
        raise ValueError("no audio was received")
    body, _ = _post(cfg["voice_base_url"].rstrip("/") + "/api/voice/listen", audio,
                    content_type or "application/octet-stream", cfg.get("voice_key"), timeout)
    data = json.loads(body)
    if not isinstance(data, dict) or not isinstance(data.get("text"), str):
        raise ValueError("the voice server did not return {text}")
    return {"text": data["text"][:4000], "stub": False}

#!/bin/bash
# The 48 - AI's Best Mate: one-command deploy on a fresh Linux box.
#
#   bash deploy.sh            install and start on port 8048
#   PORT=9000 bash deploy.sh  use another port
#
# What it does: checks Python, runs the tests, creates a sign-in password on this box (never in
# the repo), and starts the app - as a systemd service when run as root on a systemd machine,
# otherwise as a background process from this folder.
# What it never does: touch DNS, domains, Caddy, or any other service. It only ever starts,
# restarts or replaces its own "best-mate" service. Putting it behind a public address is a
# separate, deliberate step: the Caddy lines are printed at the end for you to add yourself.
set -euo pipefail
cd "$(dirname "$0")"
HERE="$(pwd)"
PORT="${PORT:-8048}"

echo "== 1. Python =="
python3 -c 'import sys; assert sys.version_info >= (3, 8), "Python 3.8 or newer is needed"; print("python", sys.version.split()[0])'

echo "== 2. Tests (money maths, fabrication check, end to end) =="
python3 -m unittest discover -s tests 2>&1 | tail -4

mkdir -p data
new_env() {   # $1 = file to create with a fresh password and session secret
  python3 - "$1" "$PORT" <<'PY'
import os, secrets, sys
path, port = sys.argv[1], sys.argv[2]
fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
with os.fdopen(fd, "w") as fh:
    fh.write("APP_PASSWORD=%s\nSESSION_SECRET=%s\nHOST=127.0.0.1\nPORT=%s\n" % (
        secrets.token_urlsafe(12), secrets.token_hex(32), port))
PY
}

echo "== 3. Start =="
if [ "$(id -u)" = "0" ] && [ -d /run/systemd/system ]; then
  ENV_FILE=/etc/best-mate.env
  [ -f "$ENV_FILE" ] || { new_env "$ENV_FILE"; FRESH=1; }
  OWNER="$(stat -c %U "$HERE")"
  cat > /etc/systemd/system/best-mate.service <<UNIT
[Unit]
Description=The 48 - AI's Best Mate (quoting app)
After=network.target

[Service]
User=$OWNER
WorkingDirectory=$HERE
EnvironmentFile=$ENV_FILE
ExecStart=/usr/bin/env python3 $HERE/server.py
Restart=on-failure
NoNewPrivileges=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target
UNIT
  systemctl daemon-reload
  systemctl enable best-mate >/dev/null 2>&1
  systemctl restart best-mate
  HOW="systemd service 'best-mate'  (logs: journalctl -u best-mate)"
else
  ENV_FILE="$HERE/data/.env"
  [ -f "$ENV_FILE" ] || { new_env "$ENV_FILE"; FRESH=1; }
  if [ -f data/server.pid ] && kill -0 "$(cat data/server.pid)" 2>/dev/null; then
    kill "$(cat data/server.pid)"; sleep 1          # only ever our own earlier process
  fi
  set -a; . "$ENV_FILE"; set +a
  nohup python3 "$HERE/server.py" > data/server.log 2>&1 &
  echo $! > data/server.pid
  HOW="background process $(cat data/server.pid)  (logs: $HERE/data/server.log, stop: kill \$(cat $HERE/data/server.pid))"
fi

PORT_NOW="$(grep '^PORT=' "$ENV_FILE" | cut -d= -f2)"
for _ in $(seq 1 20); do
  if python3 -c "import urllib.request,sys; urllib.request.urlopen('http://127.0.0.1:$PORT_NOW/api/health', timeout=2)" 2>/dev/null; then UP=1; break; fi
  sleep 0.5
done
[ "${UP:-}" = "1" ] || { echo "The app did not come up on port $PORT_NOW. Is something else using it? Check the logs."; exit 1; }

echo
echo "== APP UP =="
echo "Open on this box:  http://127.0.0.1:$PORT_NOW/"
echo "Running as:        $HOW"
if [ "${FRESH:-}" = "1" ]; then
  echo "Sign-in password:  $(grep '^APP_PASSWORD=' "$ENV_FILE" | cut -d= -f2)   (shown once; stored in $ENV_FILE)"
else
  echo "Sign-in password:  unchanged, in $ENV_FILE"
fi
echo "Jane's voice and the AI model are optional: add VOICE_BASE_URL / LLM_BASE_URL (and keys) to $ENV_FILE and run this again."

echo "To reach it from a phone it needs HTTPS (the offline mode and the microphone both require it)."
echo "When you are ready, add this to your Caddyfile yourself - this script does not touch Caddy or DNS:"
echo

class HttpError(Exception):
    def __init__(self, status, message):
        super().__init__(message)
        self.status = status


class App:
    """Everything the handlers share."""

    def __init__(self, cfg):
        self.cfg = cfg
        self.store = Store(cfg["db"])
        self.started = time.time()
        self.fails = []                               # times of recent failed sign-ins
        self.lock = threading.Lock()
        try:
            with open(os.path.join(WEB, "logo-mark.jpg"), "rb") as fh:
                self.logo = fh.read()
        except OSError:
            self.logo = None
        secret = cfg["session_secret"]
        if not secret:                                # generated once on this machine, never in the repo
            path = os.path.join(os.path.dirname(os.path.abspath(cfg["db"])), ".session-secret")
            try:
                with open(path) as fh:
                    secret = fh.read().strip()
            except OSError:
                secret = secrets.token_hex(32)
                fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_TRUNC, 0o600)
                with os.fdopen(fd, "w") as fh:
                    fh.write(secret)
        self.secret = secret.encode()

    # ---- sessions
    def token(self):
        expiry = str(int(time.time()) + SESSION_DAYS * 86400)
        return expiry + "." + hmac.new(self.secret, expiry.encode(), hashlib.sha256).hexdigest()

    def valid(self, token):
        expiry, _, sig = (token or "").partition(".")
        if not expiry.isdigit() or int(expiry) < time.time():
            return False
        return hmac.compare_digest(sig, hmac.new(self.secret, expiry.encode(), hashlib.sha256).hexdigest())

    def sign_in(self, password):
        with self.lock:
            cutoff = time.time() - 300
            self.fails = [t for t in self.fails if t > cutoff]
            if len(self.fails) >= 5:
                raise HttpError(429, "Too many wrong passwords. Wait five minutes and try again.")
            if not hmac.compare_digest(str(password).encode(), self.cfg["app_password"].encode()):
                self.fails.append(time.time())
                raise HttpError(401, "Wrong password.")
            self.fails = []
        return self.token()

    # ---- the modes shown in the health strip
    def modes(self):
        return {"voice": "live" if self.cfg["voice_base_url"] else "stub",
                "ai": "model" if self.cfg["llm_base_url"] else "built-in reader",
                "auth": bool(self.cfg["app_password"])}


def dollars(v, name):
    try:
        return money.to_cents(v)
    except ValueError:
        raise ValueError("%s must be a dollar amount" % name)


class Handler(BaseHTTPRequestHandler):
    app = None
    server_version = "BestMate/" + VERSION
    protocol_version = "HTTP/1.1"

    # ---------------------------------------------------------------- plumbing
    def log_message(self, fmt, *args):
        if os.environ.get("BESTMATE_LOG"):
            sys.stderr.write("%s %s\n" % (time.strftime("%H:%M:%S"), fmt % args))

    def send(self, status, body, ctype="application/json; charset=utf-8", extra=None):
        if not isinstance(body, (bytes, bytearray)):
            body = json.dumps(body, ensure_ascii=False).encode()
        self.send_response(status)
        self.send_header("Content-Type", ctype)
        self.send_header("Content-Length", str(len(body)))
        self.send_header("Cache-Control", "no-store" if self.path.startswith("/api/") else "no-cache")
        self.send_header("X-Content-Type-Options", "nosniff")
        self.send_header("Referrer-Policy", "no-referrer")
        self.send_header("Content-Security-Policy", CSP)
        for k, v in (extra or {}).items():
            self.send_header(k, v)
        self.end_headers()
        if self.command != "HEAD":
            self.wfile.write(body)

    def body(self, limit):
        try:
            length = int(self.headers.get("Content-Length") or 0)
        except ValueError:
            raise HttpError(400, "Bad request.")
        if length > limit:
            self.close_connection = True
            raise HttpError(413, "That is too large.")
        return self.rfile.read(length) if length else b""

    def json(self):
        raw = self.body(MAX_JSON)
        try:
            data = json.loads(raw or b"{}")
        except ValueError:
            raise HttpError(400, "That was not valid JSON.")
        if not isinstance(data, dict):
            raise HttpError(400, "Send a JSON object.")
        return data

    def signed_in(self):
        if not self.app.cfg["app_password"]:
            return True
        for part in (self.headers.get("Cookie") or "").split(";"):
            name, _, value = part.strip().partition("=")
            if name == "bm" and self.app.valid(value):
                return True
        return False

    def cookie(self, value, age):
        secure = "; Secure" if self.headers.get("X-Forwarded-Proto") == "https" else ""
        return {"Set-Cookie": "bm=%s; Path=/; Max-Age=%d; HttpOnly; SameSite=Strict%s" % (value, age, secure)}

    # ---------------------------------------------------------------- dispatch
    def do_GET(self):
        self.handle_any()

    do_HEAD = do_POST = do_PUT = do_DELETE = do_GET

    def handle_any(self):
        path = self.path.split("?", 1)[0]
        try:
            if not path.startswith("/api/"):
                return self.static(path)
            if self.command == "HEAD":
                raise HttpError(405, "Not allowed.")
            self.api(path)
        except HttpError as exc:
            self.send(exc.status, {"error": str(exc)})
        except LookupError as exc:
            self.send(404, {"error": str(exc) or "Not found."})
        except PermissionError as exc:
            self.send(409, {"error": str(exc)})
        except ValueError as exc:
            self.send(400, {"error": str(exc)})
        except BrokenPipeError:
            pass
        except Exception as exc:                       # never leak a traceback to the phone
            sys.stderr.write("error on %s %s: %r\n" % (self.command, path, exc))
            self.send(500, {"error": "Something went wrong on the server."})

    def static(self, path):
        if self.command not in ("GET", "HEAD"):
            raise HttpError(405, "Not allowed.")
        if path in STATIC:
            name, ctype = path.lstrip("/"), STATIC[path]
        elif APP_ROUTES.match(path):
            name, ctype = "index.html", "text/html; charset=utf-8"
        else:
            raise HttpError(404, "Not found.")
        with open(os.path.join(WEB, name), "rb") as fh:
            extra = {"Service-Worker-Allowed": "/"} if name == "sw.js" else None
            self.send(200, fh.read(), ctype, extra)

    def query(self):
        from urllib.parse import parse_qs
        return {k: v[0] for k, v in parse_qs(self.path.partition("?")[2]).items()}

        if path == "/api/logout" and m == "POST":
            return self.send(200, {"ok": True}, extra=self.cookie("gone", 0))
        if not self.signed_in():

        # ---- settings and vendors
        if path == "/api/settings":

    # ---------------------------------------------------------------- line helpers
    def qty(self, v):
        q = money.to_milli(v)
        if not 0 < q <= 100_000_000:
            raise ValueError("quantity must be more than zero")
        return q

    def line_from(self, d):
        """A new line: from the library (sku), or one a person typed with their own cost and price."""
        store = self.app.store
        qty = self.qty(d.get("qty", 1))
        if d.get("sku"):
            part = store.part(str(d["sku"]))
            if not part:
                raise LookupError("That part is not in the library.")
            return drafting.library_line(store, part, qty)
        desc = " ".join(str(d.get("description", "")).split())
        if not desc:
            raise ValueError("describe the item")
        return {"sku": None, "description": desc, "unit": str(d.get("unit") or "ea")[:12], "qty_milli": qty,
                "unit_cost_cents": dollars(d.get("unit_cost", ""), "cost"),
                "unit_sell_cents": dollars(d.get("unit_sell", ""), "price"), "price_status": "manual"}

    def line_changes(self, qid, lid, d):
        store = self.app.store
        q = store.quote(qid)
        line = next((ln for ln in (q or {}).get("lines", []) if ln["id"] == lid), None)
        if not line:
            raise LookupError("No such line.")
        changes = {}
        if "qty" in d:
            changes["qty_milli"] = self.qty(d["qty"])
        if d.get("sku"):                                # swap in a library part (this is how a flag is cleared)
            part = store.part(str(d["sku"]))
            if not part:
                raise LookupError("That part is not in the library.")
            new = drafting.library_line(store, part, changes.get("qty_milli", line["qty_milli"]))
            changes.update({k: new[k] for k in ("sku", "description", "unit", "unit_cost_cents", "unit_sell_cents", "price_status")},
                           flagged=0, flag_reason="")
        elif "unit_sell" in d or "unit_cost" in d:      # a person sets the price: their call, recorded as manual
            sell = dollars(d["unit_sell"], "price") if "unit_sell" in d else line["unit_sell_cents"]
            cost = dollars(d["unit_cost"], "cost") if "unit_cost" in d else line["unit_cost_cents"]
            if sell is None or cost is None:
                raise ValueError("give both your cost and your price for this item")
            changes.update(unit_sell_cents=sell, unit_cost_cents=cost, price_status="manual", flagged=0, flag_reason="")
        if "description" in d:
            desc = " ".join(str(d["description"]).split())
            if not desc:
                raise ValueError("describe the item")
            changes["description"] = desc[:300]
        return changes


def make_server(cfg):
    loopback = cfg["host"] in ("127.0.0.1", "localhost", "::1")
    if not cfg["app_password"] and not loopback:
        raise SystemExit("Refusing to listen on %s without APP_PASSWORD: customer data would be open to the network."
                         % cfg["host"])
    handler = type("BoundHandler", (Handler,), {"app": App(cfg)})
    server = ThreadingHTTPServer((cfg["host"], cfg["port"]), handler)
    server.daemon_threads = True
    return server


def main():
    cfg = config.load(ROOT)
    server = make_server(cfg)
    modes = server.RequestHandlerClass.app.modes()
    print("The 48 - AI's Best Mate %s on http://%s:%d/" % (VERSION, cfg["host"], server.server_address[1]))
    print("  voice: %s | drafting: %s | sign-in: %s" % (modes["voice"], modes["ai"], "on" if modes["auth"] else
          "OFF (fine on this machine only; set APP_PASSWORD before putting it behind a public address)"))
    print("  database: %s" % cfg["db"], flush=True)
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        print()
    finally:
        server.server_close()


if __name__ == "__main__":
    main()

class Client:
    def __init__(self, base):
        self.base, self.cookie = base, ""

    def call(self, method, path, body=None, raw=None, ctype="application/json"):
        data = raw if raw is not None else (json.dumps(body).encode() if body is not None else None)
        req = urllib.request.Request(self.base + path, data=data, method=method)
        if data is not None:
            req.add_header("Content-Type", ctype)
        if self.cookie:
            req.add_header("Cookie", self.cookie)
        try:
            with urllib.request.urlopen(req, timeout=10) as r:
                status, headers, payload = r.status, r.headers, r.read()
        except urllib.error.HTTPError as e:
            status, headers, payload = e.code, e.headers, e.read()
        if headers.get("Set-Cookie"):
            self.cookie = headers["Set-Cookie"].split(";")[0]
        if headers.get("Content-Type", "").startswith("application/json"):
            payload = json.loads(payload)
        return status, payload, headers

def pdf_drawn(data):
    """Every string the PDF draws, read straight from its content streams."""
    text = b""
    for m in re.finditer(rb"/FlateDecode >>\nstream\n(.*?)\nendstream", data, re.S):
        text += b" ".join(re.findall(rb"\((.*?)\) Tj", zlib.decompress(m.group(1)))) + b" "
    return text.decode("latin-1").replace("\\(", "(").replace("\\)", ")")


def pdf_text(data):
    """The text of a PDF: via pdftotext when it is installed, else from its content streams."""
    if shutil.which("pdftotext"):
        with tempfile.NamedTemporaryFile(suffix=".pdf") as fh:
            fh.write(data)
            fh.flush()
            return subprocess.run(["pdftotext", "-layout", fh.name, "-"], capture_output=True, text=True, check=True).stdout
    return pdf_drawn(data)

class Parsing(unittest.TestCase):
    def test_dollars_to_cents_rounds_half_up(self):
        self.assertEqual(m.to_cents("12.345"), 1235)
        self.assertEqual(m.to_cents("12.344"), 1234)
        self.assertEqual(m.to_cents("$1,200.50"), 120050)
        self.assertEqual(m.to_cents(80), 8000)
        self.assertEqual(m.to_cents("-50"), -5000)
        self.assertEqual(m.to_cents("0.1") + m.to_cents("0.2"), 30)          # the float trap: 0.1 + 0.2

    def test_rubbish_is_refused(self):
        for bad in ("", "abc", "1.2.3", "NaN", "Infinity", None):
            with self.assertRaises(ValueError):
                m.to_cents(bad)
        for bad in ("", "-1", "lots", "NaN"):
            with self.assertRaises(ValueError):
                m.to_milli(bad)

    def test_quantities_and_percentages(self):
        self.assertEqual(m.to_milli("2.5"), 2500)
        self.assertEqual(m.to_milli(10), 10000)
        self.assertEqual(m.to_bp("12.5"), 1250)
        self.assertEqual(m.to_bp("30%"), 3000)


class Pricing(unittest.TestCase):
    def test_vendor_discount(self):
        self.assertEqual(m.discounted_cost(100000, 1250), 87500)             # $1,000 less 12.5%
        self.assertEqual(m.discounted_cost(999, 3333), 666)                  # 999 x 0.6667 = 666.03
        self.assertEqual(m.discounted_cost(5000, 0), 5000)
        self.assertEqual(m.discounted_cost(5000, 10000), 0)
        with self.assertRaises(ValueError):
            m.discounted_cost(5000, 10001)

    def test_markup(self):
        self.assertEqual(m.sell_from_cost(90000, 3000), 117000)              # $900 + 30%
        self.assertEqual(m.sell_from_cost(333, 3333), 444)                   # 333 x 1.3333 = 443.99
        self.assertEqual(m.sell_from_cost(1, 5000), 2)                       # 1.5c rounds half-up to 2c
        self.assertEqual(m.sell_from_cost(0, 3000), 0)

    def test_extension_rounds_once(self):
        self.assertEqual(m.extend(1560, 3000), 4680)                         # 3 m at $15.60
        self.assertEqual(m.extend(333, 2500), 833)                           # 2.5 x $3.33 = $8.325 -> $8.33
        self.assertEqual(m.extend(1, 500), 1)                                # half a cent rounds up
        self.assertEqual(m.extend(1, 499), 0)

    def test_floats_and_negatives_are_refused(self):
        for args in ((10.5, 1000), (-1, 1000), (100, -1), (True, 1000)):
            with self.assertRaises(ValueError):
                m.extend(*args)


class Gst(unittest.TestCase):
    def test_ten_percent_rounded_once_on_the_total(self):
        self.assertEqual(m.gst_on(192135), 19214)                            # $1,921.35 -> $192.135 -> $192.14
        self.assertEqual(m.gst_on(100000), 10000)
        self.assertEqual(m.gst_on(5), 1)                                     # 0.5c rounds up
        self.assertEqual(m.gst_on(4), 0)

    def test_gst_is_not_summed_per_line(self):

        self.assertEqual((t["total_ex_gst_cents"], t["gst_cents"], t["total_inc_gst_cents"]), (15, 2, 17))


class QuoteTotals(unittest.TestCase):
    # the acceptance-test job: 2.5 kW split, back-to-back, 4 h labour, 30% markup, seed prices
    LINES = [
        {"qty_milli": 1000, "unit_cost_cents": 90000, "unit_sell_cents": 117000},
        {"qty_milli": 3000, "unit_cost_cents": 1200, "unit_sell_cents": 1560},
        {"qty_milli": 3000, "unit_cost_cents": 350, "unit_sell_cents": 455},
        {"qty_milli": 1000, "unit_cost_cents": 2800, "unit_sell_cents": 3640},
        {"qty_milli": 3000, "unit_cost_cents": 400, "unit_sell_cents": 520},
        {"qty_milli": 1000, "unit_cost_cents": 2500, "unit_sell_cents": 3250},
        {"qty_milli": 1000, "unit_cost_cents": 1800, "unit_sell_cents": 2340},
        {"qty_milli": 10000, "unit_cost_cents": 300, "unit_sell_cents": 390},
        {"qty_milli": 1000, "unit_cost_cents": 4500, "unit_sell_cents": 5850},
        {"qty_milli": 1000, "unit_cost_cents": 3500, "unit_sell_cents": 4550},
    ]

    def test_whole_quote_to_the_cent(self):
        t = m.quote_totals(self.LINES, labour_hours_milli=4000, labour_cost_rate_cents=6000, labour_sell_rate_cents=11000)
        self.assertEqual(t["external_cost_cents"], 113950)      # 900 + 36 + 10.50 + 28 + 12 + 25 + 18 + 30 + 45 + 35
        self.assertEqual(t["materials_sell_cents"], 148135)     # the same lines at sell
        self.assertEqual(t["labour_cost_cents"], 24000)         # 4 h x $60
        self.assertEqual(t["labour_sell_cents"], 44000)         # 4 h x $110
        self.assertEqual(t["total_ex_gst_cents"], 192135)
        self.assertEqual(t["gst_cents"], 19214)
        self.assertEqual(t["total_inc_gst_cents"], 211349)      # $2,113.49
        self.assertEqual(t["net_profit_cents"], 54185)          # 1921.35 - 1139.50 - 240.00
        self.assertEqual(t["margin_bp"], 2820)                  # 541.85 / 1921.35 = 28.20%
        self.assertEqual(t["unpriced_lines"], 0)

    def test_inc_gst_always_equals_ex_plus_gst(self):
        for adjust in (-5000, 0, 1, 333, 99999):
            t = m.quote_totals(self.LINES, 4000, 6000, 11000, adjust)
            self.assertEqual(t["total_inc_gst_cents"], t["total_ex_gst_cents"] + t["gst_cents"])
            self.assertEqual(t["net_profit_cents"], t["total_ex_gst_cents"] - t["external_cost_cents"] - t["labour_cost_cents"])

    def test_adjustment_moves_price_and_profit_together(self):
        base = m.quote_totals(self.LINES, 4000, 6000, 11000, 0)
        less = m.quote_totals(self.LINES, 4000, 6000, 11000, -10000)
        self.assertEqual(less["total_ex_gst_cents"], base["total_ex_gst_cents"] - 10000)
        self.assertEqual(less["net_profit_cents"], base["net_profit_cents"] - 10000)
        self.assertEqual(less["gst_cents"], 18214)              # $1,821.35 -> $182.135 -> $182.14

    def test_flagged_and_unpriced_lines_never_reach_a_total(self):
        lines = self.LINES + [
            {"qty_milli": 1000, "unit_cost_cents": None, "unit_sell_cents": None, "flagged": True},
            {"qty_milli": 2000, "unit_cost_cents": 5000, "unit_sell_cents": 999999, "flagged": True},
            {"qty_milli": 1000, "unit_cost_cents": 100, "unit_sell_cents": None},
        ]
        t = m.quote_totals(lines, 4000, 6000, 11000)
        self.assertEqual(t["total_inc_gst_cents"], 211349)
        self.assertEqual(t["unpriced_lines"], 3)

    def test_empty_quote_and_negative_total(self):
        t = m.quote_totals([])
        self.assertEqual((t["total_inc_gst_cents"], t["margin_bp"]), (0, 0))
        with self.assertRaises(ValueError):
            m.quote_totals([], adjust_cents=-1)

    def test_a_loss_shows_as_a_negative_margin(self):
        t = m.quote_totals([{"qty_milli": 1000, "unit_cost_cents": 10000, "unit_sell_cents": 8000}])
        self.assertEqual((t["net_profit_cents"], t["margin_bp"]), (-2000, -2500))

export function h(tag, attrs, ...kids) {
  const el = document.createElement(tag);
  for (const [k, v] of Object.entries(attrs || {})) {
    if (v == null || v === false) continue;
    if (k === "class") el.className = v;
    else if (k.startsWith("on")) el.addEventListener(k.slice(2), v);
    else if (k in el && k !== "list" && k !== "form") el[k] = v;
    else el.setAttribute(k, v === true ? "" : v);
  }
  for (const kid of kids.flat(Infinity)) {
    if (kid == null || kid === false) continue;
    el.append(kid.nodeType ? kid : document.createTextNode(String(kid)));
  }
  return el;
}

// replaceChildren/append that accept the same loose children h() does (arrays, null, false)
const tidy = (kids) => kids.flat(Infinity).filter((k) => k != null && k !== false);
const fill = (el, ...kids) => el.replaceChildren(...tidy(kids));
const add = (el, ...kids) => el.append(...tidy(kids));

// ---------------------------------------------------------------- talking to the server
export async function api(method, path, body, raw) {
  if (method !== "GET" && !navigator.onLine) throw new Error("You're offline. Changes need a connection.");
  const opts = { method, credentials: "same-origin", headers: {} };
  if (raw) { opts.body = raw.body; opts.headers["Content-Type"] = raw.type; }
  else if (body !== undefined) { opts.body = JSON.stringify(body); opts.headers["Content-Type"] = "application/json"; }
  let res;
  try { res = await fetch(path, opts); }
  catch (e) { setOffline(true); throw new Error(method === "GET" ? "You're offline and this isn't saved on the phone yet." : "No connection. Nothing was changed."); }
  if (method === "GET") setOffline(res.headers.get("X-From-Cache") === "1");
  if (raw && raw.blob && res.ok) return res;
  let data = {};
  try { data = await res.json(); } catch (e) { /* not JSON */ }
  if (res.status === 401 && path !== "/api/login") { showLogin(); throw new Error("Sign in to continue."); }
  if (!res.ok) throw new Error(data.error || "That didn't work (" + res.status + ").");
  return data;
}

  catch (err) { toast(err.message, true); return null; }
}

async function voiceView(box) {
  const modes = (await api("GET", "/api/settings")).modes;
  const text = h("textarea", { id: "job", placeholder: "e.g. two and a half kW Daikin split, back-to-back install, Smith job", "aria-label": "Job description" });
  const said = h("div", { class: "said" }, "Tap the mic and describe the job.");
  const mic = h("button", { class: "mic", type: "button", "aria-label": "Start listening" }, h("i", { class: "ico v" }));
  let recorder = null, stream = null, chunks = [];

  const stop = () => { if (stream) stream.getTracks().forEach((t) => t.stop()); stream = null; recorder = null; mic.classList.remove("live"); mic.setAttribute("aria-label", "Start listening"); };
  mic.addEventListener("click", async () => {
    if (recorder) { recorder.stop(); return; }
    if (!navigator.mediaDevices || !window.MediaRecorder) { said.textContent = "This browser can't record. Type the job below instead."; return; }
    try { stream = await navigator.mediaDevices.getUserMedia({ audio: true }); }
    catch (e) { said.textContent = "The microphone is blocked. Type the job below instead."; return; }
    chunks = [];
    recorder = new MediaRecorder(stream);
    recorder.ondataavailable = (e) => { if (e.data.size) chunks.push(e.data); };
    recorder.onstop = async () => {
      const type = recorder.mimeType || "audio/mp4";
      stop();
      said.textContent = "Jane is listening back…";
      const out = await act(() => api("POST", "/api/voice/listen", undefined, { body: new Blob(chunks, { type }), type }));
      if (!out) { said.textContent = "Jane couldn't hear that. Type the job below instead."; return; }
      text.value = out.text;
      said.textContent = out.stub ? "Sample sentence only: Jane's ears aren't connected yet. Edit it to match the job." : "Check Jane heard you right, then draft.";
    };
    recorder.start();
    mic.classList.add("live"); mic.setAttribute("aria-label", "Stop listening");
    said.textContent = "Listening… tap again when you're done.";
  });

  const draftBtn = h("button", { class: "btn cta wide", type: "button", onclick: async () => {
    if (!text.value.trim()) { toast("Describe the job first.", true); return; }
    draftBtn.disabled = true;
    const out = await act(() => api("POST", "/api/ai/draft-quote", { job_description: text.value, create: true, via: "voice" }));
    draftBtn.disabled = false;
    if (!out) return;
    const todo = out.line_items.filter((l) => l.flagged).length;
    speak("Drafted a quote" + (out.customer_name ? " for " + out.customer_name : "") + ". " +
      (todo ? todo + " item" + (todo === 1 ? " needs" : "s need") + " a price from you." : "Have a look, then review and send."));
    go("/quote/" + out.quote_id);
  } }, "Draft the quote");

  add(box, h("h1", {}, "Jane"), h("p", { class: "sub" }, "Say the job. Jane drafts it; you set the price."),
    h("div", { class: "jane-stage" }, mic, said),
    modes.voice === "stub" ? h("div", { class: "warn-box small" }, "Jane's voice server isn't connected yet, so the mic returns a sample sentence and she answers with a chime. Typing the job works now.") : null,
    h("h2", {}, "The job"), text, h("div", { class: "actions" }, draftBtn),
    h("p", { class: "small dim" }, "Drafting: " + (modes.ai === "model" ? "your AI model reads the job, then every item and price is checked against your parts library." :
      "built-in reader. Prices only ever come from your parts library.")));
  return stop;
}

}

      [h("div", { class: "empty" }, "Nothing in the library matches.")]));
  };

  dlg.addEventListener("close", () => dlg.remove());

  dlg.showModal();

}

async function quoteView(box, id) {

  const change = async (fn, done) => { const out = await act(fn, done); if (out && out.quote) { q = out.quote; draw(); } return out; };
  const put = (body) => change(() => api("PUT", "/api/quotes/" + id, body));
  const field = (label, key, type = "text") => h("label", { class: "f" }, label,
    h("input", { type, value: q[key], disabled: q.state !== "draft", onchange: (e) => put({ [key]: e.target.value }) }));

  function lineRow(ln) {
    const editable = q.state === "draft";
    const amount = ln.flagged ? "no price" : money(Math.round(ln.unit_sell_cents * ln.qty_milli / 1000));
    const head = h("div", { class: "row spread" },
      h("div", { class: "grow" }, h("div", { class: "d" }, ln.description),
        h("div", { class: "small dim mono" }, qty(ln.qty_milli) + " " + ln.unit + (ln.flagged ? "" : " × " + money(ln.unit_sell_cents)),
          ln.price_status === "placeholder" && q.state === "draft" ? h("span", { class: "badge warn" }, "check price") : null,
          ln.price_status === "manual" ? h("span", { class: "badge" }, "your price") : null)),
      h("div", { class: "a" }, amount));
    const row = h("div", { class: "line" + (ln.flagged ? " flag" : "") }, head);
    if (ln.flagged) add(row, h("div", { class: "why" }, ln.flag_reason));
    if (!editable) return row;

    if (open !== ln.id && !ln.flagged) {
      head.style.cursor = "pointer";
      head.addEventListener("click", () => { open = ln.id; draw(); });
      return row;
    }
    const qIn = h("input", { inputmode: "decimal", value: qty(ln.qty_milli), "aria-label": "Quantity" });
    const cIn = h("input", { inputmode: "decimal", value: ln.unit_cost_cents == null ? "" : plain(ln.unit_cost_cents), placeholder: "0.00", "aria-label": "Your cost each" });
    const sIn = h("input", { inputmode: "decimal", value: ln.unit_sell_cents == null ? "" : plain(ln.unit_sell_cents), placeholder: "0.00", "aria-label": "Your price each" });

          const priced = sIn.value.trim() !== "" || cIn.value.trim() !== "";
          const changed = ln.flagged || sIn.value !== (ln.unit_sell_cents == null ? "" : plain(ln.unit_sell_cents)) || cIn.value !== (ln.unit_cost_cents == null ? "" : plain(ln.unit_cost_cents));
          if (priced && changed) { body.unit_sell = sIn.value; body.unit_cost = cIn.value; }
          else if (ln.flagged) { toast("Pick a part, or enter your cost and price.", true); return; }
          open = null;
          await change(() => api("PUT", "/api/quotes/" + id + "/lines/" + ln.id, body), "Saved");
        } }, "Save"),
        h("button", { class: "btn sm line", type: "button", onclick: () => partPicker((p) =>
          change(() => api("PUT", "/api/quotes/" + id + "/lines/" + ln.id, { sku: p.sku, qty: qIn.value }), "Part swapped in")) }, "Pick a part"),

        ln.flagged ? null : h("button", { class: "btn sm quiet", type: "button", onclick: () => { open = null; draw(); } }, "Cancel"))));
    return row;
  }

  function customItem() {

    dlg.addEventListener("close", () => dlg.remove());
    document.body.append(dlg); dlg.showModal();
  }

    const hours = h("input", { inputmode: "decimal", value: qty(q.labour_hours_milli), disabled: !draft, "aria-label": "Labour hours", onchange: (e) => put({ labour_hours: e.target.value || "0" }) });
    const pdf = (label, cls) => h("a", { class: "btn " + cls, href: "/api/quotes/" + id + "/pdf", download: "" }, label);

    fill(box, 
      h("div", { class: "row spread" }, h("a", { href: "/", "data-link": true, class: "small" }, "‹ Quotes"),
        h("span", { class: "row" }, q.source === "voice" || q.source === "ai" ? h("span", { class: "badge" }, "drafted by Jane") : null,
          h("span", { class: "badge " + q.state }, STATE_LABEL[q.state]))),
      h("h1", {}, q.customer_name || "New quote"),
      h("p", { class: "sub mono" }, q.number + (q.sent_at ? " · sent " + when(q.sent_at) : " · not sent")),

      h("div", { class: "card" }, h("div", { class: "total" }, h("span", { class: "dim" }, "Total inc GST"), h("span", { class: "big" }, money(t.total_inc_gst_cents))),
        h("div", { class: "small dim mono" }, money(t.total_ex_gst_cents) + " ex GST + " + money(t.gst_cents) + " GST")),

      q.flags.length ? [h("h2", {}, "Drafting warnings"), h("div", { class: "warn-box" }, h("b", {}, "Jane wasn't sure about these"),

// ---------------------------------------------------------------- parts library
async function partsView(box) {
  const list = h("div", { class: "card" });
  const search = h("input", { type: "search", placeholder: "Search 2.5kW, isolator, SKU…", "aria-label": "Search parts" });
  const cat = h("select", { "aria-label": "Category" });
  const note = h("div");
  let offset = 0, timer;
  const load = async (more) => {
    offset = more ? offset + 50 : 0;
    let data;
    try { data = await api("GET", "/api/parts?limit=50&offset=" + offset + "&q=" + encodeURIComponent(search.value) + "&category=" + encodeURIComponent(cat.value)); }
    catch (err) { fill(list, h("div", { class: "empty" }, err.message)); return; }
    if (!cat.options.length) fill(cat, h("option", { value: "" }, "All categories"), ...data.facets.categories.map((c) => h("option", { value: c }, c)));
    fill(note, data.facets.placeholder ? h("div", { class: "warn-box small" }, h("b", {}, data.facets.placeholder + " of " + data.facets.count + " prices are placeholders."),
      " They are stand-ins, not supplier prices. Import your supplier list below to replace them.") : h("p", { class: "small dim" }, data.facets.count.toLocaleString("en-AU") + " parts, all priced from your lists."));
    const rows = data.items.map((p) => h("div", { class: "line" }, h("div", { class: "row spread" },
      h("div", { class: "grow" }, h("div", { class: "d" }, p.name), h("div", { class: "small dim mono" }, p.sku + " · " + (p.vendor || "no vendor") +
        (p.price_status === "placeholder" ? " · " : ""), p.price_status === "placeholder" ? h("span", { class: "badge warn" }, "placeholder") : null)),
      h("div", { class: "right" }, h("div", { class: "a mono" }, money(p.unit_sell_cents)), h("div", { class: "small dim mono" }, "cost " + money(p.unit_cost_cents) + " / " + p.unit)))));
    if (!more) fill(list, );
    else list.querySelector(".more")?.remove();
    add(list, ...(rows.length || more ? rows : [h("div", { class: "empty" }, "Nothing matches.")]));
    if (offset + data.items.length < data.total) add(list, h("button", { class: "btn quiet wide more", type: "button", onclick: () => load(true) }, "Show more (" + (data.total - offset - data.items.length) + ")"));
  };
  search.addEventListener("input", () => { clearTimeout(timer); timer = setTimeout(() => load(false), 220); });
  cat.addEventListener("change", () => load(false));

  const f = {};
  const inp = (key, label, extra = {}) => h("label", { class: "f" }, label, f[key] = h("input", { type: "text", ...extra }));
  const file = h("input", { type: "file", accept: ".csv,text/csv", "aria-label": "Supplier price list CSV" });
  add(box, h("h1", {}, "Parts"), h("p", { class: "sub" }, "Your priced library. Sell price is your cost, less vendor discount, plus your markup."),
    note, h("div", { class: "pad0" }), h("div", { class: "stack" }, search, cat), h("div", { class: "pad0" }), list,
    h("h2", {}, "Import a supplier price list"),
    h("div", { class: "card stack" }, h("p", { class: "small dim" }, "CSV with a header row. Needs sku, name, cost. Optional: category, brand, vendor, unit, kw. Existing SKUs are updated."),
      file, h("button", { class: "btn line", type: "button", onclick: async () => {
        if (!file.files[0]) { toast("Choose a CSV file first.", true); return; }
        const out = await act(async () => api("POST", "/api/parts/import", undefined, { body: await file.files[0].text(), type: "text/csv" }));
        if (out) { toast("Imported " + out.imported + " parts."); file.value = ""; load(false); }
      } }, "Import")),
    h("h2", {}, "Add one part"),
    h("div", { class: "card stack" }, inp("sku", "SKU"), inp("name", "Name"), h("div", { class: "two" }, inp("cost", "Your list cost, ex GST", { inputmode: "decimal", placeholder: "0.00" }), inp("unit", "Unit", { placeholder: "ea" })),
      h("div", { class: "two" }, inp("category", "Category"), inp("brand", "Brand")), h("div", { class: "two" }, inp("vendor", "Vendor"), inp("kw", "kW (units only)", { inputmode: "decimal" })),
      h("button", { class: "btn line", type: "button", onclick: async () => {
        const out = await act(() => api("POST", "/api/parts", Object.fromEntries(Object.entries(f).map(([k, el]) => [k, el.value]))));
        if (out) { toast("Saved " + out.sku + "."); Object.values(f).forEach((el) => { el.value = ""; }); load(false); }
      } }, "Save part")));
  await load(false);
}

// The Jarvis panel: job pipeline, quote states and a system health strip.
//
// MODULE BOUNDARY. This file is the only thing behind the /jarvis route. To graft the existing
// JARVIS console in, replace the body of mountJarvis() (or just fill the #jarvis-graft element it
// leaves at the bottom). Everything it needs arrives through the `host` argument:
//   host.api(method, path, body)   same-origin JSON calls (GET /api/jarvis/summary is the feed)
//   host.go(path)                  in-app navigation
//   host.money(cents), host.h      formatting and the element helper
// It returns a function that stops its refresh timer when the view is left.

export async function mountJarvis(root, host) {
  const { h, money } = host;
  const body = h("div", { class: "stack" }, h("div", { class: "empty" }, "Loading the pipeline…"));
  root.append(
    h("h1", {}, "Jarvis"),
    h("p", { class: "sub" }, "Where every job stands, and whether the system is healthy."),
    body,
    h("h2", {}, "Console"),
    h("div", { class: "graft", id: "jarvis-graft" },
      "The full JARVIS command console plugs in here. Until it is grafted, this panel shows the pipeline and health above.")
  );

  const LABEL = { draft: "Draft", sent: "Sent", won: "Won", lost: "Lost" };
  const ago = (ts) => {
    const s = Math.max(0, Math.round(Date.now() / 1000 - ts));
    return s < 90 ? "just now" : s < 5400 ? Math.round(s / 60) + " min ago" : s < 172800 ? Math.round(s / 3600) + " h ago" : Math.round(s / 86400) + " d ago";
  };

  async function draw() {
    let data;
    try { data = await host.api("GET", "/api/jarvis/summary"); }
    catch (err) { body.replaceChildren(h("div", { class: "empty" }, err.message)); return; }
    const p = data.pipeline, hl = data.health;
    const tiles = h("div", { class: "pipe" }, Object.keys(LABEL).map((s) =>
      h("a", { class: "card", href: "/?state=" + s, "data-link": true },
        h("span", { class: "badge " + s }, LABEL[s]), h("b", {}, String(p.states[s].count)),
        h("span", { class: "small dim mono" }, money(p.states[s].total_inc_gst_cents)))));

    const win = p.win_rate_bp === null ? "No jobs closed yet" : "Win rate " + (p.win_rate_bp / 100).toFixed(0) + "% of closed quotes";
    const attention = p.needs_attention.length
      ? h("div", { class: "stack" }, p.needs_attention.map((q) =>
          h("a", { class: "qcard", href: "/quote/" + q.id, "data-link": true },
            h("div", { class: "row spread" }, h("span", { class: "who" }, q.customer_name || "No customer yet"),
              h("span", { class: "badge " + (q.flagged_lines ? "bad" : "warn") },
                q.flagged_lines ? q.flagged_lines + " unpriced" : q.placeholder_lines + " to check")),
            h("div", { class: "small dim" }, q.number + " · " + (q.job_title || "Untitled job")))))
      : h("div", { class: "empty" }, "Nothing is waiting on you.");

    const recent = p.recent.length
      ? h("div", { class: "card stack" }, p.recent.map((e) =>
          h("div", { class: "row spread small" },
            h("span", {}, (e.number || "Quote") + " " + ({ created: "drafted", sent: "sent", won: "won", lost: "lost", draft: "reopened" }[e.kind] || e.kind) +
              (e.customer_name ? " · " + e.customer_name : "")),
            h("span", { class: "dim mono" }, ago(e.ts)))))
      : h("div", { class: "empty" }, "No activity yet.");

    const light = (ok) => { const d = h("span", { class: "dot" }); if (!ok) d.style.setProperty("--k", "var(--orange)"); return d; };
    const cell = (name, value, ok = true) => h("div", {}, h("b", {}, name), light(ok), value);
    const health = h("div", { class: "health" },
      cell("Database", hl.database),
      cell("Parts", hl.parts.toLocaleString("en-AU") + " in library"),
      cell("Prices", hl.placeholder_prices ? hl.placeholder_prices + " placeholders" : "all from suppliers", !hl.placeholder_prices),
      cell("Jane's voice", hl.voice === "live" ? "connected" : "stub, not connected", hl.voice === "live"),
      cell("Drafting", hl.ai === "model" ? "AI model" : "built-in reader"),
      cell("Sign-in", hl.auth ? "on" : "off", hl.auth),
      cell("Version", hl.version),
      cell("Up for", ago(Date.now() / 1000 - hl.uptime_s).replace(" ago", "").replace("just now", "under 2 min")));

    body.replaceChildren(
      h("h2", {}, "Pipeline"), tiles, h("p", { class: "small dim" }, win),
      h("h2", {}, "Needs your eye"), attention,
      h("h2", {}, "Recent"), recent,
      h("h2", {}, "System health"), health);
  }

  await draw();
  const timer = setInterval(() => { if (!document.hidden) draw(); }, 20000);
  return () => clearInterval(timer);
}

// Offline support. The app shell and the last quotes, parts and settings this phone fetched
// are kept so a tradie with one bar of reception can still open and read their quotes.
// Nothing is ever written while offline: changes are refused with a clear message instead.
const SHELL = "bm-shell-v1";
const DATA = "bm-data-v1";
const ASSETS = ["/", "/app.css", "/app.js", "/jarvis.js", "/manifest.webmanifest", "/logo-mark.jpg",
                "/icons/icon-192.png", "/icons/icon-180.png"];
const KEEP = /^\/api\/(quotes(\/\d+)?|settings|parts|jarvis\/summary)$/;

self.addEventListener("install", (e) => {
  e.waitUntil(caches.open(SHELL).then((c) => c.addAll(ASSETS)).then(() => self.skipWaiting()));
});

self.addEventListener("activate", (e) => {
  e.waitUntil(caches.keys()
    .then((keys) => Promise.all(keys.filter((k) => k !== SHELL && k !== DATA).map((k) => caches.delete(k))))
    .then(() => self.clients.claim()));
});

async function networkFirst(request, cacheName, fallbackKey) {
  const cache = await caches.open(cacheName);
  try {
    const fresh = await fetch(request);
    if (fresh.ok) cache.put(fallbackKey || request, fresh.clone());
    return fresh;
  } catch (err) {
    const saved = await cache.match(fallbackKey || request);
    if (!saved) throw err;
    const headers = new Headers(saved.headers);
    headers.set("X-From-Cache", "1");
    return new Response(await saved.blob(), { status: saved.status, headers });
  }
}

self.addEventListener("fetch", (e) => {
  const url = new URL(e.request.url);
  if (e.request.method !== "GET" || url.origin !== location.origin) return;
  if (e.request.mode === "navigate") {
    e.respondWith(networkFirst(e.request, SHELL, "/"));
  } else if (url.pathname.startsWith("/api/")) {
    if (!KEEP.test(url.pathname)) return;
    e.respondWith(networkFirst(e.request, DATA).catch(() => new Response(
      JSON.stringify({ error: "You're offline and this hasn't been saved on the phone yet." }),
      { status: 503, headers: { "Content-Type": "application/json", "X-From-Cache": "1" } })));
  } else {
    e.respondWith(networkFirst(e.request, SHELL));
  }
});
