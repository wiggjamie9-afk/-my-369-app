# Clover system

Running several AI models on the same prompt at once, having a judge score each result, improving the prompt and retrying.

## Facts
- Implemented in [[369 Forge]]: up to four leaves, a judge returning JSON with score, issues and an improved prompt, early stop at the target score. [source: repo docs/369-forge-build-brief.md]
