YouTube connection

One-time setup: in Google Cloud, enable “YouTube Data API v3”, create an OAuth client of type Desktop app, and save its JSON as data/youtube_client.json. Uploads go up private: Google restricts videos from API projects that haven't passed its audit to private, so you review and publish in YouTube Studio. This connection has only been tested against a local fake of Google, not the real service.
